## 总体结论

四个资源的课时挂载与当前课程图谱顺序一致：`L01` 对应 8.1.1“向量的概念”，`L02` 对应 8.1.2“向量的加法和减法”，`L03` 对应 8.1.3“实数与向量的乘法”，`L04` 对应 8.2.1“向量的投影”。未发现把 8.3 的独立资源恢复到生产队列，也未发现 L01-L04 资源包修改课程图谱或第 8 章课时边界。

但从沪教版顺序边界看，`L01-A01` 和 `L02-A01` 当前把有序数对、分量读数和分量运算作为课堂显性公式展示，已经接近 8.3“向量的坐标表示”和 8.3.3“向量线性运算的坐标表示”的正式内容。数学结论本身基本正确，但出现在 8.1.1 / 8.1.2 容易削弱沪教版“先几何概念与线性运算，后坐标表示”的章节节奏，因此本轮建议这两个资源必须 `hold`，先收回到几何语言后再进入数学审校。

`L03-A01` 的数乘口径较稳：`λ > 0` 同向，`λ = 0` 为零向量且方向不规定，`λ < 0` 反向，长度统一为 `|λa| = |λ||a|`。它只把网格作为拖拽背景，没有系统引入坐标运算，可建议进入 `math_review`。

`L04-A01` 的投影口径整体正确：以非零向量 `b` 的方向为投影方向，从 `a` 的终点作垂线得垂足 `F`，沿 `b` 方向读取有向投影长度，并用锐角、直角、钝角解释正、零、负。它没有提前引入 8.3 坐标公式，可建议进入 `math_review`；但需要数学审校特别确认“数量积符号”只作为 8.2.1 到 8.2.2 的过渡直观，不在本课替代完整数量积定义。

## 数学口径检查

| 资源 | 数学结论 | 审核意见 |
|---|---|---|
| `L01-A01` 向量表示与等价拖拽板 | 向量由大小和方向决定，相等向量可平移，零向量长度为 0 且方向不规定，这些口径正确。 | 最大问题不是结论错误，而是用 `AB = (x_B - x_A, y_B - y_A)` 和有序数对作为主要证据。8.1.1 更宜用“横向位移、纵向位移、大小、方向”的几何语言，避免提前把向量正式写成坐标。 |
| `L02-A01` 向量加减法构造器 | 首尾相接、平行四边形法则、`a - b = a + (-b)`、共起点时从 `B` 指向 `A` 表示 `a - b`，数学口径正确。 | 显性分量公式与有序数对运算过重，实际呈现已经接近“向量线性运算的坐标表示”。这会把 8.3.3 的算法提前塞进 8.1.2，建议 hold。 |
| `L03-A01` 数乘伸缩实验室 | `λ` 的符号决定方向，`|λ|` 决定长度倍率；`λ = 0` 或 `a` 为零向量时结果为零向量且方向不规定。 | 数学表达严谨，零向量边界清楚。网格只服务拖拽和长度直观，未把坐标表示作为算法主线，可进入数学审校。 |
| `L04-A01` 投影长度与夹角实验室 | 有向投影长度为 `|a| cosθ`，垂足在同向一侧、原点、反向一侧分别对应正、零、负；零向量边界有提示。 | 投影概念基本严谨。需注意 `θ` 的前提是两个非零向量的夹角；`b` 为零向量时投影方向不规定。数量积只宜作为符号直观和后续衔接，不宜在 L04 展开完整定义、运算律或坐标公式。 |

## 符号与课堂表达

| 问题 | 影响 | 建议给总控的处理口径 |
|---|---|---|
| 多处使用 `AB`、`CD` 表示向量 | 在课堂文稿里可能与线段 `AB` 或长度 `AB` 混淆。 | 后续资源修订时建议统一为“向量 AB”或更标准的向量记号，尤其避免 `AB = CD = (...)` 这种裸写。 |
| `L01`、`L02` 的 `Δx`、`Δy` 和有序数对过显性 | 容易让学生以为 8.1 已正式学习向量坐标。 | 若保留读数，应降级为“横向走几格、纵向走几格”的观察证据，不作为正式向量坐标或运算公式。 |
| `L04` 界面出现 `angle_degrees`、`cos_theta`、`signed_projection`、`dot_sign` | 数学含义正确，但不是课堂自然表达。 | 进入课堂试读前应改为“夹角 θ”“cos θ”“有向投影长度”“数量积符号”等中文课堂标签。 |
| `L04` 提到“数量积符号” | 可能让 L04 与 L05 边界变模糊。 | 可以保留为“下节数量积符号直观”，但不要在 L04 中证明或训练完整数量积公式。 |
