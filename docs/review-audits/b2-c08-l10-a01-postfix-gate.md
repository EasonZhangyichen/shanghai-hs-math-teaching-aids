## 数学与方法链

通过项：

- 资源明确挂在 8.4「向量的应用」，并把使用前提写成 8.1 线性运算、8.2 数量积、8.3 坐标表示之后，未把 8.3 内容提前给低课时使用。
- 主问题限定为三角形 `ABC` 中 `D` 在 `AB`、`E` 在 `AC`，比较 `DE` 的第一步建模路径，不做通用解题器。
- 默认基向量 `p = AB`、`q = AC` 时，`AD/AB = m`、`AE/AC = n` 给出 `DE = -m p + n q`，三条路径 `D -> A -> E`、`D -> B -> C -> E`、`D -> B -> E` 化简一致。
- 切换为 `p = AB`、`r = BC` 时，`AC = p + r`，`DE = (n - m)p + n r`，与代码中路径表达一致。
- “数量积/坐标法”被处理为条件性工具：只有题目要求长度、夹角、垂直或数值化时才调用；当前问题只求向量表达，因此优先基底法或路径法。这个比较是合理的。
- 没有发现把 8.3 坐标表示错误前置为本课核心的问题；坐标法只作为 8.4 已学后续工具提示，不展开坐标训练。

需保留的小风险：

- `D = mp`、`E = nq` 属于课堂中的位置向量简写；进入正式数学审校时建议确认教师脚本口头表述为 `AD = m AB`、`AE = n AC` 或“以 A 为基点的位置表达”，避免学生把点和向量混淆。
- 本题的度量方法只做“何时不用数量积/坐标法”的策略判断，没有展示“投影 -> 数量积 -> 垂直/长度”的完整链条。这符合当前题型边界，但若后续加入度量型例题，应另开资源或扩展片段，不宜塞进本板。
