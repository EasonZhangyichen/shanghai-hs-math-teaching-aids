## 数学与方法链

通过项：

- 先修关系清楚：资源明确把 8.1 线性运算作为路径与数乘基础，把 8.2 数量积作为长度、夹角、垂直问题工具，把 8.3 坐标表示作为数值化工具；这些都放在 8.4 应用课后置使用，没有提前给 8.1 或 8.2 阶段使用。
- 默认模型合理：在三角形 `ABC` 中，`D` 在 `AB` 上且 `AD/AB = m`，`E` 在 `AC` 上且 `AE/AC = n`。取 `p = AB`、`q = AC` 时，三条路径都化简到 `DE = -m p + n q`。
- 换基表达自洽：取 `p = AB`、`r = BC` 时，`AC = p + r`，页面给出的 `DE = (n - m)p + n r` 与三条路径公式一致。
- “选择向量法路径”的比较成立：基底法适合分点比例明显的问题，路径法用于逐段翻译和验证路径和不变，数量积/坐标法被限定为后续遇到长度、夹角、垂直或数值坐标时再调用。
- 没有发现把 8.3 坐标表示错误前置为本课核心的问题；坐标法只作为 8.4 已学后的策略判断，不展开坐标表示训练或坐标计算题库。

需保留的审校点：

- 页面、脚本和元数据仍使用 `D = mp`、`E = nq`、`DE = E - D` 这类位置向量简写。进入数学审校时，应确认是否统一改为 `AD = m AB`、`AE = n AC`、`DE = AE - AD`，或明确“以 A 为共同起点的位置表达”，避免学生把点和向量混读。
- “数量积/坐标法”合在一个按钮上适合当前起手策略比较；若后续补度量型例题，应拆分成独立资源或独立片段，不宜把投影、数量积、坐标法继续堆入本板。
