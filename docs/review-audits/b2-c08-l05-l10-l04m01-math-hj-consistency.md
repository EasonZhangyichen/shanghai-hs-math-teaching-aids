## L05-A01 审核意见

`L05-A01` 的定位基本符合 8.2.2：围绕 `a·b = |a||b|cosθ`，同步展示夹角 `θ`、`cosθ`、有向投影长度和 `a·b` 的正、零、负，未进入坐标公式训练，也未展开向量应用综合题。教师脚本明确提示“不展开成坐标公式课”，范围意识是正确的。

通过项：

- 数量积被解释为数量而不是向量，符合定义教学需要。
- 锐角、直角、钝角对应 `cosθ` 和 `a·b` 的符号变化，数学口径正确。
- 用 `a` 在 `b` 方向上的有向投影解释负值，符合 8.2 从投影到数量积的知识链。
- 明确排除 8.3 向量坐标表示、坐标公式训练和后续综合应用题。
- 课堂符号使用 `π`、`θ`、`|a|`、`|b|`、`a·b`，未见 `pi/theta/omega` fallback 残留。

需要修订：

1. 零向量边界下，若 `b` 为零向量，“`a` 在 `b` 方向上的有向投影长度”不应显示为普通的 0，因为 `b` 的方向不存在。当前实现把 `a` 或 `b` 接近零向量时统一返回 `projectionLength: 0`，右侧仍可能读作“`a` 在 `b` 方向上的投影 = 0”。建议区分两类边界：`a = 0, b ≠ 0` 时投影长度为 0；`b = 0` 时隐藏或改写为“投影方向未规定”。
2. SVG 画布显示完整 x/y 坐标轴和网格，虽然没有外显坐标公式，但在 8.2.2 中容易让学生误以为正在使用 8.3 坐标表示。若进入正式审校，建议弱化坐标轴读数，或明确这是拖拽背景网格，不作为本课公式来源。
3. `metadata` 的 `cognitive_action` 为“投影”，课程图谱中该资源为“比较”。不构成数学错误，但后续总控若统一资源标签，可考虑将主认知动作改为“比较”或在说明中写清“用投影支撑比较”。

结论：`L05-A01` 接近可审校状态，但以上边界未修前不建议通过本轮 `math_review`。

## L10-A01 审核意见

`L10-A01` 挂载在 8.4「向量的应用」，从沪教版顺序看可以使用 8.3 后的坐标表示、线性运算坐标化和数量积坐标形式，因此“比较基底法、坐标法、数量积法的第一步建模路径”本身不构成 8.3 前置。

通过项：

- 课时归属在 8.4，位于 8.3 之后，使用“坐标法”作为应用路径是顺序上允许的。
- 初始设计限定 1 到 2 个典型几何问题，只比较第一步建模路径，不做通用解题器，方向符合资源必要性原则。
- 当前占位内容未提前教授 8.3 坐标公式，也未把未讲内容塞进 8.2。

需要修订：

1. 资源仍是 scaffold：`implementation.phase: content_spec_only`，`html_src_status: scaffolded`，`src/index.html` 只有占位卡片，无法审查真实数学模型。
2. `learning_goals`、`prerequisites`、`successors` 仍是模板语言，例如“相关先修知识”“后续课时学习与综合应用”，还没有落到沪教版 8.1 到 8.4 的具体知识链。
3. 若后续精修，应明确 L10 的使用前提：学生已学 8.3 的向量坐标表示、向量线性运算坐标表示，以及 8.3.4 数量积与夹角的坐标表示。否则“坐标法”会从 8.4 合理应用变成对前序内容的隐性前置。

结论：`L10-A01` 当前不能进入 `math_review`，应先完成真实数学模型、典型问题选择、三种路径的第一步对照和沪教版先修链补写。

## L04-M01 审核意见

`L04-M01` 挂载在 8.2.1「向量的投影」，作为 30 到 45 秒短导入，叙事主线“定基准方向 -> 作垂线 -> 读投影点 -> 区分有向长度正零负”符合投影课时需求。它没有进入 8.3 坐标表示，也没有处理坐标公式或分量。

通过项：

- 课时定位在 L04，主对象是有向投影长度，不是坐标表示。
- 能区分普通线段长度和有向读数，回应 L04 的核心痛点。
- README 和 review 均说明不替代后续 Applet，不处理 8.3 暂缓资源。

需要修订：

1. 文档中大量残留 fallback 数学写法：`theta`、`pi`、`0 <= theta <= pi`、`a dot b`、`cos theta`。课堂可接受表达应统一为 `θ`、`π`、`0 ≤ θ ≤ π`、`a·b`、`cosθ`。
2. L04 是“向量的投影”导入，不宜在分镜最后直接保留完整数量积定义式 `a dot b = |a||b| cos theta`。建议收束到“有向投影长度 = `|a|cosθ`”，最多用口头预告“下一课会把它与数量积联系起来”，避免把 L05 的定义提前讲完。
3. 当前 `scene.py` 只是标题卡和占位提示，没有实际作垂线、投影点和正零负动画，不能据此判断成片的几何位置、节奏和符号显示是否严谨。

结论：`L04-M01` 的导入意图正确，但在符号标准化、数量积衔接边界和真实动画补齐前，应保持 `hold_for_revision`。

## 8.3 坐标/分量前置风险

未发现三项资源把 8.3 的坐标公式训练、分量运算或数量积坐标表示正式前置到 8.2。具体判断如下：

- `L05-A01` 没有外显 `a = (x1, y1)`、`b = (x2, y2)` 或 `a·b = x1x2 + y1y2`，但画布坐标轴和内部坐标计算可能带来轻微误读风险。
- `L04-M01` 不涉及坐标或分量，主要风险不是 8.3，而是 L04 过早展示 L05 数量积完整公式。
- `L10-A01` 位于 8.4，按当前图谱本就应在 8.3 之后使用坐标法；前置风险仅发生在资源未来被提前投放或 prerequisites 写不清时。
