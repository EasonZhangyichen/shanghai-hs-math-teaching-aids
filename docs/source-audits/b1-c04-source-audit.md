## 已确认教材结构

### 章节位置

官方电子教材目录顺序为：

```text
第3章 幂、指数与对数
第4章 幂函数、指数函数与对数函数
第5章 函数的概念、性质及应用
```

因此，第 4 章应作为第 5 章抽象函数概念之前的具体函数经验。课程图谱中第 5 章的先修关系继续指向第 4 章，不反向改写为外地版本顺序。

### 第 4 章：幂函数、指数函数与对数函数

教材目录确认：

- `4.1 幂函数`
- `4.2 指数函数`
- `4.3 对数函数`

正文“目”标题确认：

- `4.1` 下有 `1 幂函数的定义与图像`、`2 幂函数的性质`
- `4.2` 下有 `1 指数函数的定义与图像`、`2 指数函数的性质`
- `4.3` 下有 `1 对数函数的定义与图像`、`2 对数函数的性质`

正文内容可确认的教学线索：

- 幂函数强调指数固定、自变量作底，并指出幂函数定义域与指数取值有关；正文用若干典型幂函数图像引出定义域、单调性和对称差异。
- 指数函数强调底数固定、指数为变量，规定底数 `a > 0` 且 `a != 1`；正文比较 `a > 1` 和 `0 < a < 1` 两种图像与单调性。
- 对数函数强调底数固定、真数为变量，定义域为正实数；正文明确对数运算是指数运算的逆运算，并说明指数函数与对应对数函数图像关于直线 `y = x` 对称。
- 第 4 章复习题和例题中出现指数增长、对数估算和简单实际模型线索，但常规比较大小、求定义域和代数化简仍主要属于纸笔训练。

## 数字化必要性筛选

### 保留为候选 digital_entry_points

1. `4.1.2 幂函数的性质`：保留 Applet 候选“幂函数指数变化图像实验室”。
   - 数字化价值：幂函数的定义域、单调性和对称性随指数类型变化，静态板书通常只能列举少量图像；交互滑块或分类切换能让学生连续比较正指数、负指数、分数指数、奇偶分母等差异，尤其能显化原点、负半轴和坐标轴附近的边界变化。
   - 生产边界：只服务“指数改变导致性质改变”的观察和归纳，不做常规求定义域题库。

2. `4.2.2 指数函数的性质`：保留 Applet 候选“指数函数底数变化与增长比较器”。
   - 数字化价值：底数从 `0 < a < 1` 到 `a > 1` 时，图像的单调方向、过定点、趋近横轴和增长速度会同步变化；拖动底数比静态表格更容易暴露“底数越大增长越快”和“底数小于 1 时衰减”的动态关系。
   - 生产边界：不把指数函数定义背诵、常规比较大小或指数不等式求解做成可视化。

3. `4.3.2 对数函数的性质`：保留 Applet 候选“指数对数互反图像镜像板”。
   - 数字化价值：指数函数和对数函数互为反函数的核心是变量角色互换与图像关于 `y = x` 对称；拖动点并同步交换坐标能比板书更清楚地展示点、定义域和值域如何互换，也能提前支撑第 5 章反函数。
   - 生产边界：只演示互反关系和图像对称，不做对数定义背诵或换底公式练习。

4. `4.3.2 对数函数的性质`：保留 Applet 候选“幂指数对数增长模型对比板”。
   - 数字化价值：幂函数、指数函数和对数函数在同一坐标尺度下增长差异明显，但手动画图难以兼顾尺度、参数和局部/远端差异；数字化可切换线性/对数坐标、拖动观察点、比较表格与图像，帮助学生把第 4 章三类函数整理成增长模型语言。
   - 生产边界：只作为章节整理或模型对比候选；未终核前禁止 scaffold，且生产前应再次确认是否与第 5 章函数应用或后续建模资源合并。

### 暂不制作或仅保留为纸笔/教师脚本

- `4.1.1 幂函数的定义与图像` 中定义背诵、列点描图和常规求定义域：纸笔和板书足够，暂不制作独立资源。
- `4.2.1 指数函数的定义与图像` 中指数函数定义、底数条件和简单描点：可用教师脚本和板书，不单独制作动画。
- `4.3.1 对数函数的定义与图像` 中对数函数定义、真数大于 0 的常规定义域题：以纸笔练习更高效，不做可视化。
- 比较大小、指数/对数不等式、换底公式应用、代数化简和常规实际题计算：暂不进入 Applet 或 Manim；如后续需要，优先做错因诊断而不是可视化。
