## 与第 8 章“平面向量”的承接关系

- `8.1` 向量概念和线性运算提供“有向线段 / 自由向量 / 平行四边形法则”的语言，直接承接到 `9.2` 的复数向量表示和复数加法几何意义。
- `8.3` 向量坐标表示提供“有序实数对表示位移分量”的语言，直接承接到复数 `a + bi` 与复平面点 `(a, b)`、向量 `(a, b)` 的一一对应。
- `8.2` 与 `8.3.4` 的长度、夹角、数量积坐标公式，支撑学生把复数的模理解为复平面中点到原点的距离。
- 第 7 章三角函数的角、弧度、单位圆与第 8 章方向/长度语言共同支撑 `*9.4` 的三角形式；若学校实际讲授选学内容，复数乘法的几何意义应回到“模相乘、辐角相加”的旋转缩放直觉。

本轮只保留数字化明显优于板书或纸笔的候选；其余内容建议暂不数字化。

### 建议暂不数字化

| 内容 | 原因 | 建议处理 |
| --- | --- | --- |
| `9.1.1` 复数引入与四则运算 | 主要是代数规则、运算闭包和符号操练，板书推导与纸笔练习更高效 | 教师脚本、纸笔例题、普通随堂练习 |
| `9.1.2` 实部、虚部与共轭 | 概念本身可板书；共轭的几何意义可并入 `L04-A01`，不单独做 Applet | 普通诊断或并入模与共轭对照 |
| `9.3` 实系数一元二次方程 | 判别式、求根与方程讨论适合板书和纸笔推导；单独动画容易只是把推导动起来 | 教师脚本、纸笔任务、普通诊断 |
| `*9.4.1` 复数的三角形式 | 极坐标直觉有价值，但可由 `L07-A01` 承接；若只做代数式转换，数字化收益不足 | 先暂不单列，待确认学校进度和课堂痛点 |
