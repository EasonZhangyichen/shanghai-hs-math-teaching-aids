### 数学语言特别关注

- pi 分数和一般式：`pi/2 + kpi`、`2kpi`、`-pi/2 + kpi` 等必须统一渲染和口头表达，避免漏写 `k in Z`。
- 定义域和值域：正弦、余弦定义域和值域较稳定；正切必须把定义域断点、渐近线和图像断裂同时说清。
- 周期：正弦/余弦最小正周期为 `2pi`，正切为 `pi`；参数图像需区分 `2pi / |omega|` 与课堂默认 `omega > 0` 的口径。
- 单调区间：正弦、余弦区间端点口径需与教材一致；正切只能在每个连续定义区间内单调递增。
- 渐近线：正切渐近线来自 `cos x = 0` 和函数无定义，不应只作为图像记忆线。
