- 不把“第2章复习课”写成教材 lesson。
- 保留 3 个数字化必要性较明确的 `digital_entry_points`，但全部在 note 中标明“未终核前禁止 scaffold”，并由 `chapter_resource_priorities` 继续强调 blocked 状态。

## 沪教版顺序与先修后续关系

```text
第 1 章 集合与逻辑
  -> 第 2 章 等式与不等式
  -> 第 3 章 幂、指数与对数
  -> 第 4 章 幂函数、指数函数与对数函数
  -> 第 5 章 函数的概念、性质及应用
```

- 第 2 章为第 3 章提供等式变形、取值范围、不等式性质、基本不等式和条件意识；指数幂、对数定义、换底公式都需要先检查变形条件。
- 第 2 章为第 4 章提供函数性质研究中的不等式比较工具，例如幂函数单调、指数/对数单调与增长比较。
- 第 2 章为第 5 章提供定义域、值域、函数零点、用函数观点求解方程与不等式的代数基础；教材第 2 章章首已明确本章采用代数方法，函数观点后续再学。
- 课程图谱不得按其他版本常见顺序改成“先函数概念，再等式与不等式”或把二次不等式完全移入函数章节。

### 暂不制作或仅保留为纸笔/教师脚本

| 内容 | 判断 | 处理 |
| --- | --- | --- |
| 等式性质、方程解集、参数方程分类 | 关键是等价变形、分类讨论和取值范围；板书推理与纸笔练习更高效 | 暂不制作可视化 |
| 一元二次方程解集、韦达定理和恒等式系数比较 | 属于代数推导和运算训练，数字化价值不明显 | 暂不制作可视化 |
| 不等式性质、移项、同向可加、乘除变号 | 需要严谨推理和反例意识；可做教师追问或纸笔诊断，不适合独立 Applet | 暂不制作可视化 |
| 分式不等式求解 | 主要是同号/异号、定义域排除和转化为整式不等式；机械化简和符号表足够 | 暂不制作可视化 |
| 含绝对值不等式求解 | 简单距离意义和分段讨论可用数轴板书讲清；若后续发现错因集中，可并入“解集数轴实验室”而非另建资源 | 本轮不单独制作 |
| 三角不等式 | 教材本章以实数绝对值证明为主，几何意义在向量、复数后续更自然；本轮单独动画价值不如平均值不等式明确 | 暂不制作可视化 |
| 常规移项、因式分解、解方程刷题、机械化简 | 不满足数字化必要性门槛 | 明确不进入 backlog |
