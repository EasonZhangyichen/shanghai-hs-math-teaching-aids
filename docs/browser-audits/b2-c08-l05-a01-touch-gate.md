## 结论

`SH-HS-MATH-HJ-B2-C08-L05-A01` 的数学主线仍对齐 8.2.2「向量的数量积的定义与运算律」：用 `a·b = |a||b|cosθ`、夹角、余弦符号和 `a` 在 `b` 方向上的有向投影解释数量积的正、零、负。页面没有引入 8.3 坐标公式训练，也没有出现 `D=mp`、`E=nq` 这类不适合本课的简写。

本轮发现并修复一个触控风险：平台 iframe 缩放后，向量端点透明拖拽热区在 `1280x720` 下曾缩到约 33px。已将透明 `hit-handle` 半径从 24 扩大到 32，并新增资源内自检断言。复测后直达页拖拽热区为 57-58px，平台 iframe 内为 44-51px。

`npm run verify` 通过后已再次执行 Playwright 复核；下表记录的是 post-verify 结果。

## 数学与课堂口径

- `120°` 场景显示 `θ = 120° = 2π/3`、`cosθ = -0.50`、投影为负、`a·b < 0`，投影方向解释准确。
- 将 `a` 拖到原点时显示“a 为零向量，投影 = 0”，并说明这不是两个非零向量垂直。
- 将 `b` 拖到原点时显示“投影方向未规定”，并说明不能说 `a` 在 `b` 方向上的投影等于 0。
- 教师 12 分钟流程仍建议只使用 `30°`、`90°`、`120°` 三个角按钮完成主线，零向量边界作为口头辨析，不增加学生书写量。

## 剩余风险

- 平台课时页外层仍需滚动到 L05 资源卡，尤其 `1024x768` 下资源卡较深；本轮只确认滚到 iframe 后的内部首屏通过。
- Browser 插件可完成导航和 DOM 快照，但截图命令在本地页超时；本轮精确复核使用 Playwright CLI 完成。
- 真实教室触控屏、Safari、低配 Windows 教师机和投屏缩放仍需一线设备复核。
- 第 8 章课时边界仍需纸质教材或已登录 dolearning / 上海数字教学平台终核。
