## 审核口径

- 视角：一线高中数学教师在一节课中嵌入 12 到 18 分钟数字教具片段。
- 检查项：教师脚本是否可讲、学生任务是否可操作、暂停点是否自然、追问是否能暴露关键错因、时间是否可控。
- 不替代事项：不替代真实教师试讲，不替代学生小组限时试做，不替代触控大屏可用性复核。

## `SH-HS-MATH-HJ-B2-C07-L01-A01`

建议状态：`ready_for_teacher_trial`

### 课堂时间线建议

| 时间 | 教师动作 | 学生任务 | 暂停点与追问 |
| --- | --- | --- | --- |
| 0:00-2:00 | 只显示单位圆、动点 P 和角 x，拖到第一象限与关键位置。 | 口头读出 P 的纵坐标和 `sin x` 的关系。 | 暂停在 `π/2`：`sin x` 取哪个坐标？为什么不是横坐标？ |
| 2:00-6:00 | 打开投影线和图像点 `Q = (x, sin x)`，依次停在五个关键角。 | 填关键值表中的 `sin x` 和 Q 坐标。 | 暂停在 `π`：Q 的横坐标是 P 的横坐标，还是角 x 的弧度量？ |
| 6:00-10:00 | 隐藏完整轨迹，先让学生预测，再打开轨迹生成。 | 完成“从 0 到 π/2 上升、从 π/2 到 π 下降”的短答。 | 暂停在 `π/2 -> π`：P 仍在上半圆，为什么 Q 会下降？ |
| 10:00-14:00 | 打开周期延拓，显示 x 与 `x + 2π` 的等高点。 | 用“终边、单位圆上的点、纵坐标”解释周期。 | 暂停在同终边对照：曲线重复来自图像记忆，还是来自 P 相同？ |
| 14:00-16:00 | 打开归纳，收一条小组解释。 | 提交“正弦曲线来自单位圆，是因为……”一句话。 | 追问错误表达：若学生写 `(cos x, sin x)` 是图像点，要求区分 P 与 Q。 |

### 可讲性

教师脚本按照“旧知复现 -> 新表征 -> 预测生成 -> 周期解释 -> 一句话收束”推进，符合 16 分钟片段的课堂呼吸。每一步都有可见操作对象：P、投影线、Q、轨迹和周期延拓，教师不需要额外解释复杂控件。

### 学生任务负荷

原学生活动有 5 个任务，整套全部书面完成会偏重。试读时建议只把任务一关键值表、任务三 Q 坐标解释、任务四周期一句话设为必做；任务二预测和任务五快速诊断改为口头检查。

### 错因暴露能力

追问能直接暴露三类关键错因：

- 把图像点 Q 误写为单位圆点 P。
- 把横轴的 x 当成单位圆横坐标 `cos x`。
- 只背周期 `2π`，说不出同终边和纵坐标相同的理由。

### 必须真实确认

- 真实教师需确认第 4 环节周期解释 4 分钟是否够用，必要时压到 3 分钟。
- 小组限时试做需确认关键值表加两句解释是否能在 6 到 7 分钟内完成。
- 需要触控或教室大屏确认周期延拓开启后，同终边对照点是否足够清楚。

## `SH-HS-MATH-HJ-B2-C07-L05-A01`

建议状态：`hold_for_revision`

### 主要原因

现有教师脚本建议 25 分钟，完整覆盖 A、omega、phi、两种变换顺序和图像反推参数。这个结构适合一节课中的主活动或两段式活动，但不适合直接作为 12 到 18 分钟课堂片段试读。若强行压缩，最容易牺牲的是 `-phi / omega` 的讨论时间和变换顺序的辨析时间，而这两点正是本资源的核心错因。

### 可行的 18 分钟压缩试读线

| 时间 | 教师动作 | 学生任务 | 暂停点与追问 |
| --- | --- | --- | --- |
| 0:00-2:00 | 初始显示 `y = sin x` 与参数函数重合，说明本资源只看 `y = A sin(omega x + phi)`。 | 口头说出当前振幅、周期、平移量。 | 暂停：哪些参数会互相干扰？ |
| 2:00-6:00 | 只切 A 模式，调 `A = 2` 与 `A = -1`。 | 填 A 表中“最高点、最低点、是否翻折、振幅”。 | 暂停在 `A = -1`：振幅是 A 还是 `|A|`？最大点会不会对调？ |
| 6:00-10:00 | 切 omega 模式，调 `omega = 2` 与 `0.5`。 | 记录一个周期长度，回答 omega 与周期是否同向。 | 暂停在 `omega = 2`：周期为什么是 `π`？ |
| 10:00-15:00 | 切 phi 模式，比较 `omega = 1, phi = π/2` 与 `omega = 2, phi = π/2`。 | 填 `-phi / omega` 两行，解释为什么同一个 phi 平移不同。 | 暂停：`phi = π/2` 一定左移 `π/2` 吗？ |
| 15:00-18:00 | 只做一个反推出口题：先看 `|A|`，再看周期，最后用零点求平移。 | 提交“最容易错的参数”和图像证据。 | 追问：为什么不能先猜 phi？ |

### 建议删减或后移

- “变换顺序比较”建议单独作为第二个 12 到 15 分钟片段，或与 `L05-M01` Manim 组合使用。
- “从图像反推参数”在压缩版中只保留一个出口题，不展开完整表格。
- 学生活动任务四的两种顺序表格和任务五完整反推表不建议同时放进 18 分钟片段。

### 错因暴露能力

资源的追问设计能暴露核心错因，但需要时间：

- `omega` 变大误以为周期变大。
- 把 `+phi` 机械说成右移或左移。
- 忘记平移量要除以 `omega`。
- `A < 0` 时只说振幅变大，漏掉关于 x 轴翻折。

当前问题不是数学追问不足，而是课堂时间过密。

### 必须真实确认

- 需要真实教师确认：7.3 这一课是否允许 25 分钟主活动；若只能给 12 到 18 分钟，应先改写压缩脚本。
- 需要 3 到 4 人小组限时试做：A、omega、phi 三个任务能否在 13 分钟内完成记录与讨论。
- 需要教师判断 `omega > 0` 的边界说明是否会引发学生追问 `omega < 0`；若会，应准备一句拓展收束，但不要展开。
- 不需要数学跟进；当前建议是教学节奏修订，不是数学口径退回。

### 课堂时间线建议

| 时间 | 教师动作 | 学生任务 | 暂停点与追问 |

| 0:00-3:00 | 从单位圆终边斜率进入，拖动 `0 -> π/4`。 | 读 `sin x`、`cos x`，说出 `tan x` 是商。 | 暂停：哪个量为 0 会导致正切不存在？ |
| 3:00-6:00 | 切主值区间，记录 `-π/4`、`0`、`π/4`。 | 完成任务一表格核心三点。 | 暂停在端点：为什么 `-π/2`、`π/2` 不能画实点？ |
| 6:00-11:00 | 切逼近渐近线，先做 `π/2` 左右两侧。 | 填任务三两行：`cos x` 符号、`tan x` 变化、趋向。 | 暂停：渐近线是图像的一部分吗？左右趋势为什么相反？ |
| 11:00-14:00 | 切周期对照，打开 `x + π` 点。 | 比较两行：`x = -π/4`、`x = 0`。 | 暂停：为什么正切周期不是 `2π`？ |
| 14:00-16:00 | 打开归纳面板，收定义域、渐近线、周期。 | 提交“断开图像”的解释。 | 追问连续 S 形错误：哪些 x 不能取，图像应该在哪里断开？ |

### 可讲性

脚本的 3+3+5+3+2 分钟结构可落地，且每个环节对应一个清晰控件模式：主值区间、逼近渐近线、周期对照。第 3 环节 5 分钟是关键，应优先保证 `π/2` 左右两侧趋势，不必在同一片段中完整展开 `-π/2`。

### 学生任务负荷

任务设置已有分层：逼近渐近线只要求 `π/2` 左右两行，周期对照第三行给快完成小组。这个负荷适合 16 分钟片段。试读时建议任务二一般式只收定义域和渐近线，不要求所有渐近线表格都书面填满。

### 错因暴露能力

追问能直接暴露四类关键错因：

- 把正切图像跨渐近线连起来。
- 只背 `π/2`，不能说出来源是 `cos x = 0`。
- 左右逼近方向反了。
- 受正弦、余弦迁移，把周期写成 `2π`。

### 必须真实确认

- 真实教师需确认第 3 环节“逼近渐近线”5 分钟是否足够学生说清左右趋势。
- 小组限时试做需确认任务一、任务三和出口解释能否在 8 到 9 分钟内完成。
- 触控屏或教室大屏需确认靠近渐近线时滑块和读数不会因为数值变化太快而影响讲解。
