## 审校口径

### 正弦与余弦相位对照

- 同一角 `x` 下，`sin x` 来自单位圆动点纵坐标，`cos x` 来自横坐标。
- 关键角值序列必须严谨：`sin x` 为 `0, 1, 0, -1, 0`；`cos x` 为 `1, 0, -1, 0, 1`。
- 相位关系为 `cos x = sin(x + π/2)`，可用 `x = 0` 检查方向：`cos 0 = 1 = sin(π/2)`。
- 如果使用“左移 `π/2`”的图像语言，必须明确是正弦图像得到余弦图像的方向，不能让学生误写成 `sin(x - π/2)`。
- 相位关系不能替代余弦函数的单位圆横坐标来源。

### 参数变换顺序 Manim

- 对 `y = A sin(ωx + φ)`，振幅为 `|A|`，周期为 `2π / |ω|`；若本视频主线限制 `ω > 0`，必须在 metadata、分镜和画面语言里写清。
- 样例 `y = -1.5 sin(2x + π/2)` 应改写为 `y = -1.5 sin(2(x + π/4))`，相位平移为向左 `π/4`，不是向左 `π/2`。
- `A = -1.5` 表示纵向放大到 `1.5` 倍并关于 `x` 轴翻折，不应被说成横向变化。
- 视频画面和文档中的课堂可见文本必须使用 `π`、`ω`、`φ` 等数学符号，避免 `pi/omega/phi` 主导课堂显示。
- 渲染后必须检查 mp4、webm 和 poster 是否存在，poster 应截取主体清晰画面。

### 正切性质分段观察

- 定义域必须写成 `x ≠ π/2 + kπ, k ∈ Z`，并与渐近线位置一致。
- 值域为 `R`，需要用每个分支从负无穷延伸到正无穷解释，不把渐近线误解为值域缺口。
- 周期为 `π`，用 `tan(x + π) = tan x` 的点对或分支平移支撑。
- 正切函数为奇函数，`tan(-x) = -tan x`，用关于原点对称的点对支撑。
- 单调性只能表述为在每个连续定义区间 `(-π/2 + kπ, π/2 + kπ), k ∈ Z` 上递增，不能说在整个定义域上递增。
- 图像不能跨渐近线连线；滑块或播放不能在渐近线处制造连续穿越的误导。
