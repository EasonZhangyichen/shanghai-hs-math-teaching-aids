## 审校口径

### 正弦性质

- 定义域为 `R`，值域为 `[-1, 1]`，最小正周期为 `2π`。
- 零点为 `x = kπ`，最大值点为 `(π/2 + 2kπ, 1)`，最小值点为 `(-π/2 + 2kπ, -1)`，其中 `k ∈ Z`。
- 单调区间、对称轴和对称中心必须注明周期延拓，不得只写一个局部区间或局部点。
- 交互应帮助学生从图像比较归纳性质，不能只把结论列表贴在图旁边。

### 参数变换

- 对 `y = A sin(ωx + φ)`，振幅为 `|A|`，最小正周期为 `2π / |ω|`。
- 当 `ω > 0` 时，水平平移量可写为 `-φ / ω`；如果资源限制 `ω > 0`，必须在 metadata 和课堂脚本中说清楚边界。
- `A < 0` 的作用必须区分为关于 `x` 轴翻折与振幅大小，不能把负号吞进“振幅为 A”。
- 多参数联动应有单参数观察、变换顺序和参数反推的认知脚手架，避免让学生只拖滑块看热闹。

### 显示与体验

- 所有 `π/2`、`2π`、`ω`、`φ`、`kπ` 等课堂可见文本必须使用数学符号表达，不出现 `pi/2`、`Theta`、`omega`、`phi` 或不清楚的英文占位。
- Applet 在平台 iframe 中首屏应可看到核心图像，不应被底部操作栏或浏览器窗口截断。
- Diagnosis 的题干、选项、反馈、评分规则和教师说明必须保持同一套参数口径和错因标签。
