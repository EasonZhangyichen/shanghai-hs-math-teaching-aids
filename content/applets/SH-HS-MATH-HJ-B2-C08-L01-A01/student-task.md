# 学生活动：向量表示与等价拖拽板

## 任务 1：读出一个向量

观察蓝色 `AB`。

1. 记录 `A` 和 `B` 的坐标。
2. 计算 `Δx = x_B - x_A`，`Δy = y_B - y_A`。
3. 用一句话说明这两个分量和向量大小、方向有什么关系。

## 任务 2：判断平移后的向量

显示橙色 `CD` 后，拖动 `C` 到不同位置。

记录三次结果：

| 次数 | C 的位置 | D 的位置 | Δx | Δy | AB 与 CD 是否相等 |
| --- | --- | --- | --- | --- | --- |
| 1 |  |  |  |  |  |
| 2 |  |  |  |  |  |
| 3 |  |  |  |  |  |

结论填空：

```text
虽然起点从 A 变成 C，但是 __________ 和 __________ 没有变，
所以 AB 与 CD 表示 __________ 向量。
```

## 任务 3：找一个反例

只改变蓝色向量的终点 `B`，让长度或方向发生变化。

回答：

- 如果长度相同但方向不同，两个向量相等吗？
- 如果方向相同但长度不同，两个向量相等吗？
- 当起点和终点重合时，这个向量的长度和方向如何描述？
