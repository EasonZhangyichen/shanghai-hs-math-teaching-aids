## 核心问题

学生初学向量时常把向量理解成“画在某个位置的一根箭头”。本课件用同一位移的两条有向线段做对照，让学生看到：

- 向量由大小和方向共同决定。
- 有向线段的起点可以变化，但从起点到终点的几何位移、长度和方向不变时表示相等向量。
- 只看长度或只看方向都不足以判断向量相等。
- 零向量长度为 0，方向不规定。

## 已实现交互

- 平面网格。
- 蓝色向量 `AB`：拖动 `A` 或 `B` 改变当前向量，拖动线段整体可平移起点而保持向量不变。
- 橙色向量 `CD`：始终按向量 `AB` 的同一几何位移得到，表示平移后的相等向量；拖动 `C`、`D` 或整条橙色线段只改变起点位置。
- 同步证据：水平位移、竖直位移、向量 `AB` 与向量 `CD` 的长度相同、方向、起点对照。
- 教师控制：重置、位移辅助线、平移痕迹、四步揭示。
- 零向量边界提示：当 `A` 与 `B` 重合时显示长度为 0、方向不规定。

## 分步揭示

1. 观察：只看向量 `AB`，说出从 `A` 到 `B` 的位移。
2. 平移：显示向量 `CD`，把同一位移搬到不同起点。
3. 证据：显示水平位移、竖直位移、长度和方向，用证据判断相等。
4. 归纳：形成“大小相等、方向相同，与位置无关”的课堂结论。
