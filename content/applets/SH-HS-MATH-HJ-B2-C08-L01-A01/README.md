## 教学痛点

- 学生容易把向量绑定到起点位置，难以理解只要大小和方向相同就是同一向量。
- 零向量的方向约定、单位向量和相等向量常被机械记忆，缺少几何解释。
- 有向线段、向量记号和几何图形之间的表征切换容易断裂。

## 初始设计意图

拖动多个有向线段的起点和终点，实时判断相等、相反、平行和共线关系，突出向量的位置无关性。
