## 审校证据

- 函数对象限定为 `y = A sin(ωx + φ)`，默认不讨论竖直平移。
- 振幅写为 `|A|`；`A < 0` 明确为关于 x 轴翻折，并补充最大值点和最小值点会对调的审校口径。
- 周期使用一般式 `2π / |ω|`；本资源滑块限制 `0.5 <= ω <= 3`，因此课堂主线写清 `ω > 0`，界面显示 `2π / ω`。
- 相位/水平平移量写为 `-φ / ω`，并在界面、脚本、学生活动中强调不能把 `φ` 直接当作平移量。
- 关键点追踪口径为 `ωx + φ = kπ` 与 `ωx + φ = π/2 + kπ`，并说明 `A < 0` 时最值类别对调。
- 变换顺序呈现已区分中间曲线：先伸缩后平移显示 `y = sin(ωx)`，先平移后伸缩显示 `y = sin(x + φ)`；最终曲线相同，但最终平移量仍为 `-φ / ω`。
- 页面可见文本使用课堂符号 `π`、`ω`、`φ`、`2π / |ω|`、`sin x` 等数学语言。
