# 教师脚本：三角函数参数变化实验室

适用课时：必修第二册 7.3“函数 y = A sin(ωx + φ) 的图像”
建议时长：18 分钟主试读片段；如需展开“变换顺序比较”，另设 12 到 15 分钟第二片段
资源状态：`draft`

## 教学目标

1. 让学生分离说明 `A`、`ω`、`φ` 对图像的作用。
2. 让学生理解振幅是 `|A|`，并能说明 `A < 0` 时图像关于 x 轴翻折。
3. 让学生理解一般周期应写成上下分式：分子为 `2π`、分母为 `|ω|`；本资源限制 `ω > 0`，课堂显示时分母可写 `ω`，避免把 `ω` 与周期同向理解。
4. 让学生解释水平平移量应写成上下分式：分子为 `φ`、分母为 `ω`，前面取负号；不能只看 `φ` 的符号。
5. 让学生用“先振幅、再周期、后平移”的顺序完成一个轻量反推。

## 课前准备

- 初始参数设为 `A = 1`、`ω = 1`、`φ = 0`。
- 本 Applet 滑块限制 `0.5 ≤ ω ≤ 3`，即只讨论 `ω > 0` 的主线；`ω < 0` 的等价处理只作为一句拓展，不在试读片段展开。
- 默认显示基本曲线、参数函数曲线、中间曲线和关键点。
- 黑板预留三行：振幅 `|A|`、周期分式、水平平移分式。

## 课堂片段 A：18 分钟试读主线

本片段只完成 A、ω、φ 的单参数观察和一个出口反推，不展开完整变换顺序表。若课堂只能给 12 到 14 分钟，可保留第 1、2、3、4 环节，把第 5 环节改为口头出口题。

### 1. 建立基本参照

时长：2 分钟

操作：

- 显示 `y = sin x` 与当前参数函数重合的初始状态。
- 拖动观察点，让学生确认当前图像仍是基本正弦曲线。

提问：

- 当前振幅、周期和平移量分别是多少？
- 如果三个参数一起变，最容易混淆哪两类变化？

### 2. 单独改变 A：振幅与翻折

时长：4 分钟

操作：

- 切换到“A”单参数模式。
- 让 `A` 从 `1` 变到 `2`，再变到 `-1`。

提问：

- 最高点和最低点怎样变化？
- `A < 0` 时，图像只是“振幅变大”吗？
- 振幅应写 `A` 还是 `|A|`？
- `A < 0` 时，原来对应最大值的位置会变成最大值还是最小值？

板书建议：

```text
振幅：|A|
A < 0：关于 x 轴翻折，再按 |A| 纵向伸缩
```

### 3. 单独改变 ω：周期反向变化

时长：4 分钟

操作：

- 切换到“ω”单参数模式。
- 让 `ω` 从 `1` 增大到 `2`，再减小到 `0.5`。

提问链：

- `ω` 变大时，一个完整周期在 x 轴上占的长度变大还是变小？
- 如果周期是 `π`，`ω` 应该是多少？
- 一般周期为什么分母要写 `|ω|`？本资源为什么可以把分母写成 `ω`？

板书建议：

```text
      2π
T = -----
     |ω|

本资源限制 ω > 0，因此可写为：

      2π
T = ----
      ω

ω 越大，周期越短
```

### 4. 单独改变 φ：平移方向与除以 ω

时长：5 分钟

操作：

- 切换到“φ”单参数模式。
- 先保持 `ω = 1`，调到 `φ = π/2`。
- 再切到自由模式，把 `ω` 改为 `2`，保持 `φ = π/2`，比较平移量。

核心追问：

- `ωx + φ = 0` 时，零点在哪里？
- 图像最终水平平移量为什么是分子为 `φ`、分母为 `ω`，前面取负号？
- `φ = π/2` 一定表示左移 `π/2` 吗？

板书建议：

```text
ωx + φ = 0
      φ
x = - ---
      ω

水平平移量同上
```

### 5. 出口反推：只做一个例子

时长：3 分钟

操作：

- 保留关键点，给出当前图像。
- 让学生只按三步说依据：先看振幅，再看周期，最后用零点或最值点求平移。

学生完成一句话：

```text
我反推参数时，先看 |A|，再由周期求 ω，最后用零点或最值点求水平平移分式。
```

教师收束：

- 如果学生先猜 `φ`，追问“你看到的是 `φ`，还是最终平移量那个分式？”
- 如果学生说 `A = -1` 振幅是 `-1`，回到最高点和最低点，强调振幅是非负长度。

### 2. 比较两种变换顺序

时长：6 到 7 分钟

操作：

- 两种顺序都能到达同一条最终曲线吗？

### 3. 反推参数小练

时长：4 分钟

操作：给出一个参数状态，让学生用“振幅、周期、平移”三步口头反推。
要求：只收一组解释，不做完整表格。

### 4. 收束

时长：1 到 2 分钟

板书保留：

```text
A -> 振幅 |A|；A < 0 关于 x 轴翻折
ω -> 周期分式：分子 2π，分母 |ω|；本资源 ω > 0
φ -> 水平平移分式：分子 φ，分母 ω，前面取负号
```

## 常见误区与处理

| 误区 | 表现 | 处理方式 |
| --- | --- | --- |
| 横向伸缩反向 | `ω` 变大却说周期变大 | 显示一个完整周期长度，回到分母为 `|ω|` 的周期分式；本实验中分母可写 `ω`。 |
| 平移方向混淆 | 把 `+φ` 直接说成右移或左移 | 解方程 `ωx + φ = 0`，读出分子为 `φ`、分母为 `ω` 且前面取负号的平移量。 |
| 遗漏除以 ω | 只写平移量 `-φ` | 把 `ω = 1` 与 `ω = 2` 的同一 `φ` 对照。 |
| 忽略 A 为负 | 只说振幅变为 A | 先取 `|A|`，再说明关于 x 轴翻折。 |
| 多参数干扰 | 不能判断图像变化来源 | 回到单参数模式逐个恢复默认值。 |
