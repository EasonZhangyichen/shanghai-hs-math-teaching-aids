# 三角函数参数变化实验室

资源 ID：`SH-HS-MATH-HJ-B2-C07-L05-A01`
版本：`0.1.0`
状态：`draft`
类型：HTML Applet 可运行原型

## 资源定位

本资源对应沪教版高中数学必修第二册第 7 章 7.3“函数 `y = A sin(ωx + φ)` 的图像”。它不把参数结论直接列成表格，而是让教师和学生通过单参数锁定、变换顺序切换和关键点追踪，观察基本正弦曲线如何变成参数函数图像。

课堂使用分成一个可试读主片段和一个可选延伸片段。18 分钟主片段只做单参数观察和一个出口反推：

```text
y = sin x
-> 单独改变 A、ω、φ
-> 追踪零点和最值点
-> 归纳振幅、周期、相位平移
-> 从图像轻量反推参数
```

如需比较“先横向伸缩后平移”和“先平移后横向伸缩”，建议另设 12 到 15 分钟第二片段，或与 `SH-HS-MATH-HJ-B2-C07-L05-M01` Manim 资源组合使用，避免把过多认知动作压进同一段课堂试读。

## 为什么需要数字化

静态板书可以说明 `A` 控制振幅、`ω` 控制周期、`φ` 控制相位，但学生常常在三个地方出错：

- 把 `ω` 变大理解成周期变大。
- 把 `φ` 的符号直接当成图像平移方向。
- 多参数同时变化时无法判断哪个参数造成哪种视觉变化。

这个 Applet 只承担一个主要认知动作：变换。教师先让学生锁定单个参数，再逐步打开中间曲线和关键点，避免学生在一开始就面对完整复合变换。

## 当前 HTML 原型能力

- 支持调节 `A`、`ω`、`φ`，同步显示当前解析式、振幅、周期和相位平移量。
- 支持单参数观察模式：`A`、`ω`、`φ` 或自由组合。
- 支持切换变换顺序：先横向伸缩后平移，或先平移后横向伸缩。
- 支持显示/隐藏基本曲线、中间曲线、关键点和归纳面板。
- 支持拖动或滑块移动当前观察点，并显示当前相位 `ωx + φ`。
- 支持 Applet SDK 基础消息：`applet:ready`、`applet:stateChanged`、`applet:interaction`。

## 课堂试读建议

- 主试读片段控制在 18 分钟：2 分钟建立参照，4 分钟观察 `A`，4 分钟观察 `ω`，5 分钟观察 `φ`，3 分钟出口反推。
- 学生任务只保留 A、ω、φ 三张轻表格和一个出口反推，不要求同一片段完成完整变换顺序表。
- 可选第二片段控制在 12 到 15 分钟，专门比较中间曲线和变换顺序。
- 当前资源仍需真实教师限时试读，确认 18 分钟主线中的学生记录量和暂停点是否可控。

## 资源边界

本资源包含：

- Applet metadata、教师脚本、学生活动任务和草稿审核记录。
- `src/index.html` 可运行原型。
- 参数范围：`-2 ≤ A ≤ 2`、`0.5 ≤ ω ≤ 3`、`-π ≤ φ ≤ π`。
- 本资源主线限制 `ω > 0`：周期分式的分母可写 `ω`；一般公式的分母应写 `|ω|`。
- 默认不加入竖直平移 `k`，避免偏离本课时主线。

本资源暂不包含：

- `y = A sin(ωx + φ) + k` 的竖直平移系统讨论。
- 余弦、正切参数函数的完整对照。
- 自动生成诊断题与评分规则。
- 用真实学生作答数据训练反馈策略。

## 文件说明

- `metadata.yaml`：资源元数据、数学范围、交互状态和诊断标签。

- `student-task.md`：学生预测、观察、记录和反推参数任务。

- `src/index.html`：可独立打开或由平台 iframe 嵌入的 Applet 入口。
