## 本轮结论

建议进入 `math_review`。

本资源主线已经能够严谨表达：单位圆动点 `P = (cos x, sin x)` 的横坐标给出 `cos x`，余弦图像点为 `Q = (x, cos x)`。关键角 `0`、`π/2`、`π`、`3π/2`、`2π` 对应余弦值 `1, 0, -1, 0, 1`，周期重复来自终边相同和单位圆点重合，周期为 `2π`。

## 审校证据

- 数学表达：HTML 首屏、教师脚本、学生活动和 metadata 均突出 `P = (cos x, sin x)` 与 `Q = (x, cos x)`，没有把图像点横坐标误写为单位圆横坐标。
- 关键角：浏览器验证中分别停在 `0`、`π/2`、`π`、`3π/2`、`2π`，读数对应 `1.000, 0.000, -1.000, 0.000, 1.000`；`2π` 端点保留为 `Q = (2π, 1.000)`，不再被立即折回 `0`。
- 教学口径：正弦参照用于说明相位关系 `cos x = sin(x + π/2)`，但脚本和提示语先追问单位圆横向投影来源，避免把余弦图像机械说成“正弦平移记忆”。
- 符号显示：源文本使用 `π/2`、`3π/2`、`2π` 等数学符号；检索未发现课堂可见文案中保留 ASCII 半角角度写法或英文角变量写法。
- 浏览器体验：平台课时 `7.2.1 余弦函数的图像` 能显示目标资源卡，iframe `src` 指向 `content/applets/SH-HS-MATH-HJ-B2-C07-L03-A01/src/index.html`，iframe 首屏能看到目标标题、单位圆和公式说明。
- 交互联动：直达同一 iframe 页面验证了滑块输入、单位圆拖动、播放/暂停、重置、正弦参照、周期延拓；横向投影、余弦轨迹、正弦参照和周期延拓均能随状态变化更新。
- 命令验证：本轮 `npm run validate:content` 通过；因修改了 HTML 和 metadata，本轮也执行了 `npm run verify`，内容校验、测试和构建均通过。
