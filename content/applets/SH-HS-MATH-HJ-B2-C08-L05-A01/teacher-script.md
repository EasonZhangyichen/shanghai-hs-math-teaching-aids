# 教师脚本：数量积动态解释器

## 使用时机

建议放在「向量的数量积的定义与运算律」中，学生已经知道向量夹角和投影之后，用 10 到 12 分钟把数量积定义从公式读成几何意义。

## 课堂流程

### 1. 观察夹角

操作：保持默认 60°，拖动向量 a 或 b 的端点。

追问：

- 屏幕上变化的是向量，右侧的 a·b 是向量还是数量？
- 如果只看 |a|、|b|，能不能判断 a·b 的符号？

板书落点：

```text
a·b = |a||b|cosθ
```

### 2. 显示投影

操作：点击“下一步”，让投影段出现。把 b 拖到锐角位置，再点击 120°。

追问：

- 投影段在 b 的正方向上时，a 在 b 方向上的有向投影长度是什么符号？
- 投影段落到 b 的反方向时，为什么 a·b 会变成负数？

板书落点：

```text
a·b = |b| × a 在 b 方向上的有向投影长度
```

### 3. 典型角对照

操作：依次点击 30°、90°、120°。

追问：

- 锐角时 cosθ 的符号是什么？a·b 的符号是什么？
- 直角时投影长度为什么为 0？
- 钝角时 a·b < 0 的几何证据在哪里？

板书落点：

- 0 < θ < <math><mfrac><mi>π</mi><mn>2</mn></mfrac></math>  ⇒  a·b > 0
- θ = <math><mfrac><mi>π</mi><mn>2</mn></mfrac></math>  ⇒  a·b = 0
- <math><mfrac><mi>π</mi><mn>2</mn></mfrac></math> < θ < π  ⇒  a·b < 0

### 4. 边界提醒

操作：把 a 拖到原点，再把 b 拖到原点，各停留 10 秒口头辨析。

追问：

- a 为零向量且 b 非零时，a·b 的值是多少？这和“垂直”有什么区别？
- b 为零向量时，还能不能说“a 在 b 方向上的投影 = 0”？为什么？

收束：

只有在两个向量都不是零向量时，a·b = 0 才能用来判断两向量垂直。a 为零向量时数量积为 0，但不是垂直；b 为零向量时 b 的方向未规定，所以不说“a 在 b 方向上的投影 = 0”。这一段只作口头辨析，不增加学生书写任务。

## 使用建议

- 不要把本 Applet 展开成坐标公式课；这里只服务数量积定义和符号直观。
- 画布网格只帮助拖拽和投屏定位，不作为坐标公式或 8.3 的来源。
- 学生回答“钝角为负”时，继续追问“负号在图上在哪里”，引回投影段。
- 若课堂时间紧，可只使用 60°、90°、120° 三个按钮完成主线。
