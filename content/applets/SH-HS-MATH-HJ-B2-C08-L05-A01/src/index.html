必修第二册 8.2.2 向量的数量积

数量积动态解释器

定义读法

a·b = |a||b|cosθ

数量积的结果是数量；当 b 不是零向量时，也可读作 |b| 乘以 a 在 b 方向上的有向投影长度。网格只作拖拽背景和视觉参照，不是本课公式来源。

典型角

同步读数

长度 |a| = 4, |b| = 3
夹角 θ = 60° = π/3
余弦 cosθ = 0.50
数量积 a·b = 6.00
投影长度 a 在 b 方向上的投影 = 2.00
关系 锐角：数量积为正

符号判断

正：a·b > 0

θ 为锐角，cosθ > 0，投影段落在 b 的正方向上。

课堂收束

  • 锐角：0 < θ < π/2，cosθ > 0，所以 a·b > 0。
  • 直角：θ = π/2，cosθ = 0，所以 a·b = 0。
  • 钝角：π/2 < θ < π，cosθ < 0，所以 a·b < 0。
  • 零向量：a·b = 0，但不能把它当作两个非零向量垂直；若 b 为零向量，投影方向未规定。
