## 教学痛点

- 学生容易把数量积误认为仍是向量，忽略结果是数量。
- 数量积为零与某个向量为零、两个向量垂直之间的条件边界容易混淆。
- 运算律和几何意义之间脱节，导致代数变形缺少方向感。

## 初始设计意图

同步展示两个向量、夹角、投影和数量积数值，突出正、零、负三种区域。
