# 数量积动态解释器

资源 ID：`SH-HS-MATH-HJ-B2-C08-L05-A01`

对应课时：`SH-HS-MATH-HJ-B2-C08-L05`「向量的数量积的定义与运算律」

这是一个可直接打开的 HTML Applet 自检草稿，聚焦平面向量数量积的几何意义：

```text
a·b = |a||b|cosθ
```

页面用两个共起点向量 a、b 连接夹角 θ、cosθ、a 在 b 方向上的有向投影长度和数量积 a·b。教师可拖动两个向量，也可用 30°、60°、90°、120°、150° 典型角按钮快速形成锐角、直角、钝角对照。画布保留淡网格只是为了拖拽定位和视觉参照，不作为 8.3 坐标公式来源。

第 8 章教材来源和课时边界仍未完成纸质教材或已登录平台终核；本资源只能保持 `draft` / `self_checked_draft` / `metadata_ready` 草稿边界。

## 核心教学痛点

- 学生容易把数量积误认为向量，忽略 a·b 的结果是数量。
- 学生会背公式，但不能解释锐角、直角、钝角为什么分别对应正、零、负。
- 投影长度的“有向”意义容易断裂，导致钝角时 a·b 为负缺少几何证据。
- a·b = 0 容易被机械理解为“总是垂直”，忽略零向量边界。

## 交互设计

- 拖动蓝色向量 a 或橙色向量 b 的端点，实时更新 |a|、|b|、θ、cosθ、投影状态和 a·b。
- 点击典型角按钮，保持 |b| 不变并把 b 旋转到相对 a 的指定夹角。
- 分步揭示按“观察夹角 → 显示投影 → 连接公式 → 归纳符号”推进。
- 投影段用绿色、灰色、红色分别表示正、零、负。
- 当 b 为零向量时，读数改为“投影方向未规定”；当 a 为零向量且 b 非零时，只说明投影长度为 0 和 a·b = 0，不把它说成两非零向量垂直。

## 数学边界

- 本资源只处理数量积的几何意义和符号判断。
- 不进入 8.3 向量的坐标表示，不讲坐标公式训练；网格和原点标记仅服务拖拽与投屏观察。
- 不证明数量积运算律，只为后续运算律学习提供几何直观。
- 零向量情形下 a·b = 0，但夹角不作为垂直判定依据；若 b 为零向量，a 在 b 方向上的投影方向未规定。
