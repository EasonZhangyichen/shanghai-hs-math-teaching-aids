# 参数不等式解集数轴实验室

资源 ID：`SH-HS-MATH-HJ-B1-C02-L04-A01`

对应课时：`SH-HS-MATH-HJ-B1-C02-L04`「一元一次不等式及一元一次不等式组的求解」

这是一个可直接打开的 HTML Applet 自检草稿，聚焦含参数一次不等式：

<math><mi>a</mi><mi>x</mi><mo>+</mo><mi>b</mi><mo>□</mo><mn>0</mn></math>

其中 □ 可切换为小于、小于等于、大于、大于等于。页面用参数滑块、临界点读数和数轴阴影联动呈现：

- `a` 为正时，除以 `a` 后方向不变。
- `a` 为负时，除以 `a` 后不等号方向改变。
- 严格不等号对应空心端点，不严格不等号对应实心端点。
- `b` 的变化会移动临界点。
- `a` 等于 0 时，不再产生临界点，解集可能是全集或空集。

## 已实现交互

- 滑块调节 `a` 和 `b`，不等号按钮切换四种关系。
- 数轴实时显示解集射线、开闭端点、全集或空集。
- 临界点公式以 MathML 或页面内上下结构分式呈现，不使用横写斜杠。
- 典型状态按钮：正系数、负系数、全集、空集。
- 分步揭示：参数符号、临界点、数轴读法、退化分类。
- 离线单文件运行，不依赖外部 CDN 或网络资源。

## 数学边界

- 本资源只做含参数一次不等式解集的多表征观察，不替代常规代数推导练习。
- 不展开一元一次不等式组的交集训练。
- 不进入二次、分式、绝对值不等式。
- `a` 等于 0 时应明确说成退化判断，不称为一次不等式。
