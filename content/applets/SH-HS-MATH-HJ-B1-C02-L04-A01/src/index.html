必修第一册 2.2.1 一元一次不等式

参数不等式解集数轴实验室

当前不等式

2x − 4 ≤ 0

临界点公式： x = −ba

a > 0：方向不变 先按原不等号读 x 的范围。

参数

不等号

典型状态

同步读数

参数符号a > 0
方向向左取值
端点实心端点
临界点x = 2

解集表达

x ≤ 2

数轴从临界点向左染色，端点取到。

分类提示

  • a > 0：方向不变，直接读原不等号。
  • a < 0：方向改变，数轴阴影会翻到另一侧。
  • a = 0：没有临界点，只判断常数与 0 的大小关系。
  • 开闭：严格不等号空心端点，不严格不等号实心端点。
