# 教师脚本：参数不等式解集数轴实验室

## 使用时机

建议放在学生已经会解一元一次不等式之后，用 10 到 12 分钟专门处理“含参数系数如何分类”和“数轴解集如何表达”。

## 课堂流程

### 1. 先看参数符号

操作：保持默认状态，拖动 `a`，让 `a` 依次为正数、负数、0。

追问：

- 解不等式前，为什么要先看 `a` 的符号？
- `a` 从正数变成负数时，数轴上的阴影方向发生了什么变化？
- `a` 等于 0 时，为什么屏幕上不再显示临界点？

板书落点：

```text
先分类：a > 0，a < 0，a = 0
```

### 2. 观察临界点移动

操作：把 `a` 固定为 2，拖动 `b`。

追问：

- 哪个点把数轴分成“满足”和“不满足”的两侧？
- `b` 改变时，是端点开闭改变，还是临界点位置改变？
- 临界点为什么写成下面的分式？

板书落点：

<math><mi>x</mi><mo>=</mo><mfrac><mrow><mo>-</mo><mi>b</mi></mrow><mi>a</mi></mfrac></math>

### 3. 对照开闭端点

操作：保持 `a = 2`、`b = -4`，依次切换小于、小于等于、大于、大于等于。

追问：

- 只改变不等号时，端点位置会不会动？
- 哪些不等号对应空心端点？
- 哪些不等号对应实心端点？

板书落点：

```text
严格不等号：空心端点
不严格不等号：实心端点
```

### 4. 退化情形辨析

操作：点击“全集”和“空集”两个典型状态。

追问：

- `a = 0` 后，式子还含有 `x` 吗？
- 为什么有时所有实数都满足，有时没有实数满足？
- 这种情形是否需要在含参数讨论中单列？

收束：

含参数一次不等式的关键不是机械移项，而是先判断参数符号。参数为 0 时要单独讨论；参数不为 0 时，再看除以参数后方向是否改变，并用数轴端点开闭表达解集。

## 使用建议

- 不要把本 Applet 用成计算题刷题器，重点放在分类依据和数轴表达。
- 学生说“向左”或“向右”时，继续追问“是由 `a` 的符号还是由原不等号决定”。
- 学生漏掉 `a = 0` 时，直接切到全集或空集按钮，让他们解释为什么没有临界点。
- 若课堂时间紧，可只保留默认状态、负系数状态和两个退化状态。
