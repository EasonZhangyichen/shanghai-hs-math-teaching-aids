# 教师脚本：正弦余弦性质对照板

适用课时：必修第二册 7.2.2“余弦函数的性质”
建议时长：20 分钟
资源状态：`draft`

## 教学目标

1. 让学生比较正弦和余弦的性质差异，避免机械套用。
2. 让学生从图像端点写出正弦、余弦各自完整的单调区间一般式。
3. 让学生区分正弦和余弦的奇偶性、对称轴和对称中心。
4. 让学生用 `k ∈ Z` 表达正弦、余弦的零点、最大值点和最小值点。

## 课前准备

- 默认显示 `-2π ≤ x ≤ 4π` 上的余弦曲线和正弦参照曲线。
- 初始隐藏周期比较、单调段、对称元素、关键点表和性质归纳。
- 黑板预留三块区域：正弦/余弦差异、单调与对称、关键点一般式。

## 课堂流程

### 1. 先识别余弦主图像

时长：3 分钟

操作：

- 重置到 `x = 0`。
- 保留正弦参照曲线，拖动同步游标到 `0`、`π/2`、`π`。

提问：

- 哪条曲线是余弦？判断依据是什么？
- `x = 0` 处余弦值是多少？正弦值是多少？
- 如果直接套正弦性质，最容易先套错什么？

预期回答：

- 余弦曲线从 `(0, 1)` 开始。
- 正弦是奇函数，余弦是偶函数；关键点顺序不同。

### 2. 周期性：同高点仍相隔 2π

时长：3 分钟

操作：

- 打开“周期”层。
- 拖动当前点，观察当前余弦点与相隔 `2π` 的比较点。

板书建议：

```text
cos(x + 2π) = cos x
cos(x + 2kπ) = cos x, k ∈ Z
最小正周期：2π
```

即时纠偏：

- 如果学生写成 `kπ`，让他们比较相隔 `π` 的点：函数值一般相反。

### 3. 单调性：从余弦端点读方向

时长：5 分钟

操作：

- 打开“单调”层。
- 切换 `k = -1, 0, 1`，让学生读每段端点。

提问链：

- 当 `k = 0` 时，余弦从 `x = 0` 到 `x = π` 是上升还是下降？
- 余弦从 `x = -π` 到 `x = 0` 呢？
- 切到 `k = 1` 后，端点整体平移了多少？
- 一般式里的周期步长为什么是 `2kπ`？

板书建议：

```text
递增：[-π + 2kπ, 2kπ]
递减：[2kπ, π + 2kπ]
k ∈ Z
```

### 4. 对称性：偶函数、轴、中心分开说

时长：4 分钟

操作：

- 打开“对称”层。
- 停在正负同角位置，观察 `cos(-x) = cos x`。

提问链：

- 关于 y 轴的配对点说明了什么函数性质？
- 余弦图像的对称轴可以怎样写？
- 余弦图像有没有对称中心？它们在哪些点？

板书建议：

```text
偶函数：cos(-x) = cos x
正弦：奇函数；对称轴 x = π/2 + kπ；对称中心 (kπ, 0)
余弦：偶函数；对称轴 x = kπ；对称中心 (π/2 + kπ, 0)
k ∈ Z
```

即时纠偏：

- 如果学生说余弦是奇函数，回到 `x` 和 `-x` 的两个同高点。
- 如果把余弦中心写成 `(kπ, 0)`，提示 `x = kπ` 是余弦对称轴；余弦图像上的对应端点是 `(2kπ, 1)` 或 `(π + 2kπ, -1)`，中心应落在零点处 `(π/2 + kπ, 0)`。

### 5. 零点和最值点：不要把正弦序列搬过来

时长：4 分钟

操作：

- 打开“关键点”层。
- 让学生先读一个周期，再推广到所有周期。

板书建议：

```text
正弦零点：x = kπ
余弦零点：x = π/2 + kπ
正弦最大值点：(π/2 + 2kπ, 1)；余弦最大值点：(2kπ, 1)
正弦最小值点：(-π/2 + 2kπ, -1)；余弦最小值点：(π + 2kπ, -1)
k ∈ Z
```

提问：

- 余弦零点之间的间隔是多少？
- 最大值点之间的间隔是多少？
- 为什么余弦最大值点不能写成 `(π/2 + 2kπ, 1)`？

### 6. 收束检查

时长：1 分钟

操作：

- 打开“归纳”层。
- 逐条追问正弦和余弦每条性质在图上的证据，先找相同项，再找关键错位项。

学生完成一句话：

```text
我判断余弦函数性质时，先看余弦图像证据，再写出带 k 的一般形式，不能直接套正弦函数性质。
```

## 常见误区与处理

| 误区 | 表现 | 处理方式 |
| --- | --- | --- |
| 正弦性质迁移 | 把余弦写成奇函数或套正弦单调区间 | 保留正弦参照，比较 `x = 0` 附近的关键点顺序。 |
| 单调方向写反 | 写成 `[0, π]` 递增 | 打开单调层，从 `(0, 1)` 到 `(π, -1)` 读方向。 |
| 对称轴与中心混淆 | 把余弦中心写成 `(kπ, 0)` | 指出 `x = kπ` 是余弦对称轴；余弦中心在零点 `(π/2 + kπ, 0)`。 |
| 关键点一般式遗漏 | 只写 `0`、`π/2`、`π` | 显示多个周期，比较同类点横坐标差，并补上 `k ∈ Z`。 |
