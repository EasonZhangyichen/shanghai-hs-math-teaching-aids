# 教师脚本：向量法路径比较板

## 使用时机

建议用于 8.4「向量的应用」中“如何开始建模”的课堂片段，安排在学生已经完成 8.1 线性运算、8.2 数量积和 8.3 坐标表示之后。目标不是讲完一道综合题，而是训练学生先比较基底法、路径法、数量积/坐标法的第一步选择，再进入向量等式。

建议时长：12 到 16 分钟。

## 课堂流程

### 1. 读条件，不急于算（2 分钟）

显示第 1 步，让学生只读图：

- `D` 在 `AB` 上，`\frac{AD}{AB} = m`。
- `E` 在 `AC` 上，`\frac{AE}{AC} = n`。
- 目标向量是 `DE`。

投屏和板书呈现比例时使用上下结构分式；常见刻度也用上下结构分式，避免横向斜杠写法干扰学生的比例方向判断。

追问：

- “如果要表达 `D` 和 `E`，哪些向量最自然？”
- “这里的 `m` 是从 `A` 到 `B` 读，还是从 `B` 到 `A` 读？”

### 2. 比较第一步选择（3 到 4 分钟）

切到“第一步选择”区，依次点三类方法，只讨论起手，不展开完整解题：

- 基底法：先选 `p = AB, q = AC`，因为 D、E 都由 A 出发的边定位。
- 路径法：先选 `D -> A -> E` 或 `D -> B -> C -> E`，把移动拆成向量和。
- 数量积/坐标法：先问本题是否要求长度、夹角、垂直或数值坐标；若只是表示 `DE`，暂不作为第一步。

追问：

- “这个问题最明显的已知条件是分点比例，还是长度夹角？”
- “如果马上建坐标，会比选 `AB`、`AC` 更省吗？”
- “数量积什么时候才成为必要工具？”

### 3. 选基向量（3 分钟）

切到第 2 步，先用 `p` 表示向量 `AB`，`q` 表示向量 `AC`。让学生说出：

```text
AD = m p
AE = n q
DE = AE - AD
```

再切换到 `p = AB, r = BC`，只比较第一步建模：

```text
AC = p + r
AE = n(p + r)
```

提醒：本板不展开坐标法深算。坐标法可以作为后续复核工具，但此处先训练路径和向量等式。
若学生或教师口头说“D = mp、E = nq”，要补一句“这是以 A 为共同起点的位置向量简写”，正式板书优先写 `AD = mp`、`AE = nq`。

### 4. 比较路径（4 到 5 分钟）

切到第 3 步，依次点击三条路径：

- `D -> A -> E`
- `D -> B -> C -> E`
- `D -> B -> E`

每次让学生先用口头说路径，再看右侧等式。重点追问：

- “这一段移动对应哪一个向量？”
- “为什么 `D -> B` 是 `(1 - m)p`，而不是 `mp`？”
- “走远路会不会改变最终的向量和？”

### 5. 化简比较（2 分钟）

切到第 4 步，让学生观察三条路径化简后的结果一致：

```text
若 p 表示向量 AB，q 表示向量 AC，则 DE = AE - AD = -m p + n q。
```

板书落点：

```text
选基向量 -> 表示点 -> 拆路径 -> 合并同类向量
路径不同，向量和不变。
```

若课堂只给 12 分钟，可跳过 `AB、BC` 换基，只保留 `AB、AC` 下三条路径；若有 16 分钟，再加入换基比较。

## 常见停顿点

- 学生一上来想建坐标：追问“坐标轴怎么选，是否比 `AB`、`AC` 更省事？”
- 学生一上来套数量积：追问“这一步是否在求长度、角或垂直？”
- 学生把比例方向写反：回到 `\frac{AD}{AB}` 和 `\frac{AE}{AC}` 的起点方向。
- 学生只写结论不写路径：要求逐段说出 `D -> A`、`A -> E` 或 `D -> B` 等移动。
