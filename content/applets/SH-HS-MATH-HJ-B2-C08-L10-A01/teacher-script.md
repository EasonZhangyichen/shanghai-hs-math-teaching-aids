# 教师脚本：向量法路径比较板

## 使用时机

建议用于「向量的应用」中“如何开始建模”的课堂片段，安排在学生已经学过向量加减法、数乘、数量积和坐标表示之后。目标不是讲完一道综合题，而是训练学生先选基向量、再比较路径、最后得到向量等式的习惯。

建议时长：14 到 16 分钟。

## 课堂流程

### 1. 读条件，不急于算

显示第 1 步，让学生只读图：

- `D` 在 `AB` 上，`AD/AB = m`。
- `E` 在 `AC` 上，`AE/AC = n`。
- 目标向量是 `DE`。

追问：

- “如果要表达 `D` 和 `E`，哪些向量最自然？”
- “这里的 `m` 是从 `A` 到 `B` 读，还是从 `B` 到 `A` 读？”

### 2. 选基向量

切到第 2 步，先用 `p = AB, q = AC`。让学生说出：

```text
D = m p
E = n q
DE = E - D
```

再切换到 `p = AB, r = BC`，只比较第一步建模：

```text
AC = p + r
E = n(p + r)
```

提醒：本板不展开坐标法深算。坐标法可以作为后续复核工具，但此处先训练路径和向量等式。

### 3. 比较路径

切到第 3 步，依次点击三条路径：

- `D -> A -> E`
- `D -> B -> C -> E`
- `D -> B -> E`

每次让学生先用口头说路径，再看右侧等式。重点追问：

- “这一段移动对应哪一个向量？”
- “为什么 `D -> B` 是 `(1 - m)p`，而不是 `mp`？”
- “走远路会不会改变最终的向量和？”

### 4. 化简比较

切到第 4 步，让学生观察三条路径化简后的结果一致：

```text
若 p = AB, q = AC，则 DE = -m p + n q。
```

板书落点：

```text
选基向量 -> 表示点 -> 拆路径 -> 合并同类向量
路径不同，向量和不变。
```

## 常见停顿点

- 学生一上来想建坐标：追问“坐标轴怎么选，是否比 `AB`、`AC` 更省事？”
- 学生把比例方向写反：回到 `AD/AB` 和 `AE/AC` 的起点方向。
- 学生只写结论不写路径：要求逐段说出 `D -> A`、`A -> E` 或 `D -> B` 等移动。
