# 学生活动：向量法路径比较板

## 活动目标

学会把几何路径翻译成向量等式，比较不同路径为什么得到同一个目标向量。

## 1. 读图设元

在三角形 `ABC` 中记录：

```text
AD/AB = m
AE/AC = n
目标向量：DE
```

选择 `p = AB, q = AC` 时，先填写：

```text
D = ______
E = ______
DE = E - D = ______
```

## 2. 路径比较

分别选择三条路径，记录每条路径对应的向量和。

| 路径 | 向量和 | 化简结果 |
| --- | --- | --- |
| `D -> A -> E` |  |  |
| `D -> B -> C -> E` |  |  |
| `D -> B -> E` |  |  |

观察后回答：

- 三条路径的几何走法是否相同？
- 化简后的目标向量是否相同？
- 哪条路径最适合你在黑板上解释？为什么？

## 3. 换一组基向量

切换到 `p = AB, r = BC`，补全：

```text
AC = ______
E = n(______)
DE = ______
```

## 4. 口头表达

用一句话说明你的策略：

```text
我先选 ______ 为基向量，因为 ______；
再沿 ______ 路径分解 DE；
最后化简得到 ______。
```

## 反思

本活动不要求用坐标法完整求解。请说明：这个问题为什么可以先用向量路径分解，而不必马上建立坐标系？
