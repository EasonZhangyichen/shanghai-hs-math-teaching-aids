# 向量法路径比较板

资源 ID：`SH-HS-MATH-HJ-B2-C08-L10-A01`

对应课时：`SH-HS-MATH-HJ-B2-C08-L10`「向量的应用」

本资源是一个可直接打开的 HTML Applet 自检草稿，用于课堂上比较“同一个几何目标向量可以由不同路径得到同一向量等式”。它服务于向量法应用的第一步策略，不是题库刷题器，也不替代完整证明书写。

## 教学痛点

- 学生面对几何题时不知道先选基底、建坐标还是使用数量积。
- 几何语言转化为向量等式的第一步难，容易直接套公式。
- 证明过程中的向量路径、辅助点和坐标系选择缺少策略。

## 核心情境

三角形 `ABC` 中，点 `D` 在边 `AB` 上，点 `E` 在边 `AC` 上：

- `AD/AB = m`
- `AE/AC = n`
- 目标是把向量 `DE` 写成所选基向量的线性组合。

默认基向量为 `p = AB`、`q = AC`，此时：

```text
D = m p
E = n q
DE = -m p + n q
```

学生可以比较三条路径：

- `D -> A -> E`
- `D -> B -> C -> E`
- `D -> B -> E`

三条路径的几何走法不同，但化简后都得到同一个 `DE`。

## 已实现交互

- 拖动 `D`、`E` 或使用比例滑块改变 `m` 与 `n`。
- 切换基向量组：`AB/AC` 或 `AB/BC`。
- 切换三条路径，观察图中路径高亮和右侧向量等式同步变化。
- 按“读条件、选基、选路径、化简比较”四步揭示课堂结论。
- 使用中位线型、非对称分点、靠近顶点等预设控制投屏节奏。
