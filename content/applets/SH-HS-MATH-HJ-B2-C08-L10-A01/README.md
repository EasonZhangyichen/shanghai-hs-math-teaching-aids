## 沪教版先修链

本板只放在 8.4「向量的应用」使用，默认学生已经学过：

- 8.1 线性运算：向量加减法、数乘和路径首尾相接。
- 8.2 数量积：数量积适合处理长度、夹角、垂直等度量关系。
- 8.3 坐标表示：坐标法适合把点和向量数值化。

本板不会把这些内容合成泛化的“全能向量应用工具箱”。课堂重点是先判断本题第一步该选基底、走路径，还是等到问题需要度量/数值化时再调用数量积或坐标法。

## 教学痛点

- 学生面对几何题时不知道先选基底、建坐标还是使用数量积。
- 几何语言转化为向量等式的第一步难，容易直接套公式。
- 证明过程中的向量路径、辅助点和坐标系选择缺少策略。

## 核心情境

三角形 `ABC` 中，点 `D` 在边 `AB` 上，点 `E` 在边 `AC` 上：

- `\frac{AD}{AB} = m`
- `\frac{AE}{AC} = n`
- 目标是先判断建模起手，再把向量 `DE` 写成所选基向量的线性组合。

课堂界面与投屏说明中，分点比例和常见刻度统一使用上下结构分式；基向量组用双行紧凑卡表示，不用横向斜杠写法。

第一步选择对照：

- 基底法：先取 `p = AB`、`q = AC`，因为 `D`、`E` 都落在从 `A` 出发的两条边上。
- 路径法：先选 `D → A → E`、`D → B → C → E` 或 `D → B → E`，把每段移动翻译成向量和。
- 数量积/坐标法：先判断题目是否要求长度、夹角、垂直或数值坐标；本题只求 `DE` 的表达时暂不作为第一步。

默认基向量为 `p` 表示向量 `AB`、`q` 表示向量 `AC`。正式板书不把点 `D`、`E` 直接等同于向量，而是以 `A` 为共同起点写：

```text
AD = m p
AE = n q
DE = AE - AD = -m p + n q
```

如果课堂口头说“D 点对应 `mp`、E 点对应 `nq`”，必须补明这是以 `A` 为共同起点的位置向量简写，仍需数学教师确认该简写是否适合写入正式课堂脚本。

学生可以比较三条路径：

- `D → A → E`
- `D → B → C → E`
- `D → B → E`

三条路径的几何走法不同，但化简后都得到同一个 `DE`。

## 已实现交互

- 拖动 `D`、`E` 或使用比例滑块改变 `m` 与 `n`。
- 切换“基底法、路径法、数量积/坐标法”的第一步选择提示。
- 切换基向量组：`AB、AC` 或 `AB、BC`。
- 切换三条路径，观察图中路径高亮和右侧向量等式同步变化。
- 按“读条件、选基、选路径、化简比较”四步揭示课堂结论。
- 使用中位线型、非对称分点、靠近顶点等预设控制投屏节奏。
- 平台 iframe 下压缩首屏：路径按钮、基向量切换、路径等式、核心画板和比例滑块优先出现在 560px 高度的预览区域内。
