# 学生活动任务

资源：`SH-HS-MATH-HJ-B1-C02-L05-A01`

## 活动 A：先预测

在两个实根情形下，先不拖动，写出你的判断：

- 图像在 x 轴上方的区间是哪里？
- 图像在 x 轴下方的区间是哪里？
- 哪一个区间对应 `f(x) > 0`？哪一个区间对应 `f(x) < 0`？

## 活动 B：拖零点

拖动左、右零点。每拖一次，记录：

- 零点如何改变？
- 数轴上的解集区间端点是否同步改变？
- 严格不等式为什么不包括零点？

## 活动 C：换开口

拖动开口手柄，让开口从向上变成向下。用一句话说明：

```text
开口向上时，f(x) > 0 在哪些区间？
开口向下时，f(x) > 0 在哪些区间？
```

再写出 `f(x) < 0` 的变化。

## 活动 D：看特殊情形

分别切换“重根”和“无实根”。回答：

- 重根为什么不是严格不等式的解？
- 无实根时，为什么不能再说“中间”和“两侧”？
- 什么时候解集是 `R`？什么时候解集是 `∅`？
