# 教师脚本

资源：`SH-HS-MATH-HJ-B1-C02-L05-A01`

建议用时：12 分钟。

## 1. 看图像

先停在默认的两个实根情形。请学生只看抛物线和 x 轴：

- 图像在 x 轴上方的横坐标在哪里？
- 图像在 x 轴下方的横坐标在哪里？
- 零点把数轴分成了几个符号区间？

板书主线：

```text
图像在 x 轴上方 ⇔ f(x) > 0
图像在 x 轴下方 ⇔ f(x) < 0
```

## 2. 对数轴

点“对数轴”。拖动两个零点，让学生观察数轴上的解集区间端点同步移动。强调端点来自 `f(x) = 0`，严格不等式不包含零点。

## 3. 换开口

拖动蓝色开口手柄穿过 x 轴，形成开口向下。追问：

- 原来 `f(x) > 0` 的两侧为什么变成 `f(x) < 0`？
- 现在 `f(x) > 0` 为什么在两个零点中间？

收束语：

```text
两个实根时，开口向上：正区间在两侧，负区间在中间。
两个实根时，开口向下：正区间在中间，负区间在两侧。
```

## 4. 看边界

依次切换“重根”和“无实根”：

- 重根时，图像只在一个横坐标处等于 0，严格不等式不能把这个点放进解集。
- 无实根时，没有零点分段，要看整条图像在 x 轴哪一侧；解集可能为 `R`，也可能为 `∅`。
