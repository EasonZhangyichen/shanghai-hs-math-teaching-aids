# 二次不等式与函数符号区间联动板

资源 ID：`SH-HS-MATH-HJ-B1-C02-L05-A01`

对应课时：`SH-HS-MATH-HJ-B1-C02-L05`「一元二次不等式的求解」

这是一个 draft 级 HTML Applet 自检草稿。教师可以拖动二次函数的零点和开口手柄，观察图像在 x 轴上方或下方的位置如何同步变成数轴上的解集区间。

## 核心对应

- 图像在 x 轴上方的横坐标，对应 `f(x) > 0` 的解集区间。
- 图像在 x 轴下方的横坐标，对应 `f(x) < 0` 的解集区间。
- 两个实根时，开口向上：`f(x) > 0` 在两侧，`f(x) < 0` 在中间。
- 两个实根时，开口向下：`f(x) > 0` 在中间，`f(x) < 0` 在两侧。

页面同时保留重根和无实根按钮，用于说明严格不等式的边界：重根不是严格不等式解，且无实根时整条图像位于 x 轴同侧，所以解集可能是 `R` 或 `∅`。

## 交互能力

- 拖动左、右零点，数轴端点和解集文字同步移动。
- 拖动蓝色开口手柄，改变 `a` 的正负和大小。
- 切换“两个实根、重根、无实根”，比较端点、单点和无交点边界。
- 分步显示“看图像 → 对数轴 → 写解集 → 看边界”。
- 支持 `player:init`、`applet:ready`、`applet:stateChanged` 基础事件。

## 数学边界

本资源只服务一元二次不等式与二次函数符号区间的对应，不做因式分解刷题，不做参数二次不等式完整分类，也不把当前自检草稿升级到 `math_review`。

当前状态保持 `draft`，审核状态保持 `self_checked_draft`。
