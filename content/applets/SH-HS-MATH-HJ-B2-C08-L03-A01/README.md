## 核心问题

学生学习 `λa` 时容易只记“长度变为多少倍”，却没有把 λ 的符号和方向联系起来。本课件把原向量 `a` 与数乘后的 `λa` 放在同一起点，并允许拖动 `a` 与连续调节 `λ`，让学生看到：

- `λ > 0`：`λa` 与 `a` 同向，长度变为 `λ` 倍。
- `λ = 0`：`λa` 是零向量，长度为 0，方向不规定。
- `λ < 0`：`λa` 与 `a` 方向相反，长度变为 `|λ|` 倍。
- 拖动原向量后，上述规律仍成立，说明这不是某一幅静态图的偶然结论。

## 数字化必要性

板书可以画出几幅典型图，但很难让学生连续看到 `λ` 穿过 0 时方向和长度如何同时变化。这个 Applet 的价值在于：

- 连续变化：λ 从正到负，零向量边界自然出现。
- 操作验证：拖动原向量后，规律仍保持。
- 错因暴露：学生若只说“长度变 |λ| 倍”，会在 `λ < 0` 和 `λ = 0` 两处暴露缺口。
- 课堂节奏：教师可以停在 `λ = 0`、`λ = -1` 和分数倍处追问。
