8.1.3 · 实数与向量的乘法

数乘伸缩实验室

拖动蓝色原向量 a 的箭头端点，再移动 λ。橙色向量始终从同一起点出发表示 λa；浅色网格只作方向和长度参照。

1.50

即时读数

原向量 a |a| = 2.78
数乘向量 λa |λa| = 4.17
长度倍率 1.50 倍
方向关系 同向

三种几何含义

λ > 0

λa 与 a 同向，长度变为 λ 倍。

λ = 0

λa 是零向量，长度为 0，方向不规定。

λ < 0

λa 与 a 方向相反，长度变为 |λ| 倍。

课堂结论

当前 λ > 0：橙色 λa 沿着蓝色 a 的方向伸长或缩短，长度为 |λ||a|。

先让学生只描述“橙色箭头相对蓝色箭头怎样变”，再回到 λ 的符号。
