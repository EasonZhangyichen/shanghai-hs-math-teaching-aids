# 教师脚本：数乘伸缩实验室

## 使用时机

建议用于「实数与向量的乘法」概念形成环节，放在相反向量、零向量和向量加减法之后。预计 10 到 12 分钟，目标是把 `λa` 的长度和方向规则从图形观察中生成出来。

## 课堂流程

### 1. 观察原向量 a（2 分钟）

打开课件默认状态，只看蓝色原向量 `a` 和橙色 `λa`。

追问：

- 蓝色箭头表示哪个向量？它的大小和方向由什么决定？
- 橙色箭头和蓝色箭头共起点，它看起来发生了什么变化？
- 现在 `λ = 1.5`，能不能只说“变长了”，还需要说明什么？

板书保留：

```text
λ > 0：先猜想同向伸缩
```

### 2. 连续调节 λ（3 分钟）

拖动 λ 滑块，从 `1.5` 调到 `0.5`，再调到 `2`。让学生只描述方向和长度，不急于写公式。

追问：

- λ 仍为正数时，橙色 `λa` 的方向有没有改变？
- λ 变小到 `0.5` 时，长度是原来的几倍？
- λ 变成 `2` 时，长度和方向分别怎样变化？

板书收束：

```text
λ > 0：λa 与 a 同向，|λa| = λ|a|
```

### 3. 停在零向量边界（2 分钟）

点击 `0`，让橙色箭头收缩到起点。

追问：

- 此时 `λa` 的长度是多少？
- 还能说它和 `a` 同向或反向吗？
- 为什么这个边界不能从“长度变 |λ| 倍”一句话里草草带过？

板书收束：

```text
λ = 0：λa = 0，零向量方向不规定
```

### 4. 观察负倍数和反向（3 分钟）

点击 `-1`，再点击 `-0.5`，必要时拖动蓝色 `a` 的端点换一个方向，让学生验证规律不是固定图形造成的。

追问：

- `λ = -1` 时，`λa` 和哪个已学概念相连？
- `λ = -0.5` 时，为什么它既变短又反向？
- 负数倍的长度倍率应写成 `λ` 还是 `|λ|`？

板书收束：

```text
λ < 0：λa 与 a 方向相反，|λa| = |λ||a|
```

### 5. 归纳与迁移（2 分钟）

切到“4 归纳”，让学生口述完整规则。

最终板书：

```text
对非零向量 a：
λ > 0，λa 与 a 同向；
λ = 0，λa 为零向量，方向不规定；
λ < 0，λa 与 a 反向；
长度统一为 |λa| = |λ||a|。
```

补充边界：

```text
若 a = 0，则任意 λ 下 λa 仍为零向量。
```

## 易错点追问

- 只说“变成 |λ| 倍”时，追问方向由谁决定。
- 把 `λ = 0` 说成“方向相同但长度为 0”时，追问零向量是否规定方向。
- 把 `λ < 0` 的长度写成 `λ|a|` 时，追问长度能否为负。
- 学生把课件网格当成 8.3 坐标运算时，回到“有向线段伸缩和方向关系”，不展开坐标表示。

## 使用边界

本脚本只服务 8.1.3「实数与向量的乘法」的几何含义。暂不处理 8.3 向量坐标表示，也不进入混合运算、坐标共线判定或应用题证明。
