# 学生活动任务：交换坐标看互反

## 任务 1：找对应点

选择 a = 2，移动指数函数上的蓝色点 P，记录 P(x, a^x) 和橙色点 Q(a^x, x)。用一句话说明 Q 怎样由 P 得到。

表达要求：必须出现“交换坐标”和“互为反函数”。

## 任务 2：判断镜像轴

观察紫色连线和绿色虚线，回答：P 与 Q 是关于哪一条直线对称？为什么不能说成关于 x 轴或 y 轴对称？

表达要求：写出“关于直线 y = x 对称”。

## 任务 3：定义域和值域互换

补充并解释：

- 指数函数的定义域 R 与对数函数的值域 R 对应。
- 指数函数的值域 (0, +∞) 与对数函数的定义域 (0, +∞) 对应。

## 任务 4：单调性对照

分别切换 a = 3 与 a = 1/2，判断 `y = a^x` 与 `y = log_a x` 是递增还是递减。
