# 自检记录：指数对数互反图像镜像板

## 当前结论

建议：维持 `self_checked_draft`。

本轮只生产可运行 HTML Applet 草稿，不进入 `math_review`、`pedagogy_review`、`classroom_trial`、`stable` 或任何正式发布状态。

## 已检查项目

- 页面必须有 `y = x` 镜像参照线，并用绿色虚线标示。
- 页面必须明确 `y = a^x` 与 `y = log_a x` 互为反函数，而不是只画两条曲线。
- 观察点必须体现交换坐标：P(x, a^x) 与 Q(a^x, x)。
- `log_a x` 在 HTML 可视公式中必须用下标显示，不能裸露为普通文本。
- 属性卡片必须包含定义域、值域和单调性对应。
- 状态保持 `draft` / `self_checked_draft`。

## 数学审校关注

- 同一底数条件必须持续可见：a > 0 且 a != 1。
- 当 0 < a < 1 时，两条互反函数都应表现为严格递减。
- 对数函数定义域来自指数函数值域 (0, +∞)，不是从图像右侧机械记忆。
- 图像关于直线 y = x 对称，不应表述成关于 x 轴、y 轴或原点对称。
