# 教师脚本：指数对数互反图像镜像板

## 使用目标

用同一底数 a 的两条曲线说明：

```text
y = a^x 与 y = log_a x 互为反函数。
```

板书建议：

```text
P(x, a^x) 在指数函数上
Q(a^x, x) 在对数函数上
P 与 Q 关于直线 y = x 对称
```

## 操作流程

1. 先观察蓝色 `y = a^x`、橙色 `y = log_a x`、绿色虚线 `y = x`。
2. 移动观察点，让学生读出 P 和 Q 的坐标，强调 Q 由 P 交换坐标得到。
3. 切换 a = 2、a = 3，观察两条曲线同为严格递增。
4. 切换 a = 1/2，观察两条曲线同为严格递减。
5. 归纳：指数函数的定义域 R 与对数函数的值域 R 对应；指数函数的值域 (0, +∞) 与对数函数的定义域 (0, +∞) 对应。

本脚本仅用于 `draft` / `self_checked_draft` 草稿试教，不进入正式审校状态。
