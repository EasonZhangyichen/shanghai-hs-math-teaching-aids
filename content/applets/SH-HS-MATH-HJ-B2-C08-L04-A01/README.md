## 核心问题

学生常把“投影长度”理解成普通线段长度，看到钝角时难以接受“投影为负”。本课件让学生拖动两个向量，直接看到：

- 垂足 `F` 在投影方向的同向一侧、原点处或反向一侧。
- 有向投影长度随夹角变化而正、零、负变化。
- `cos θ` 的正负与有向投影长度同号。
- 数量积正负可以先从投影方向直观看出，但本资源不做完整数量积公式训练。

## 已实现交互

- 淡色辅助网格与方向轴。
- 蓝色向量 `a`：拖动终点 `A` 改变被投影向量。
- 橙色向量 `b`：拖动终点 `B` 改变投影方向。
- 分步揭示：夹角、垂足、有向投影长度、正负联系。
- 同步读数：夹角 `θ`、`cos θ`、有向投影长度、数量积符号。
- 典型状态：锐角例、直角例、钝角例。
- 教师控制：重置、显示/隐藏方向轴、显示/隐藏投影段。
- 边界提示：零向量或零方向向量时提示夹角或投影方向不规定。

## 分步揭示

1. 夹角：只观察两条向量的夹角变化。
2. 垂足：从 `A` 向 `b` 所在直线作垂线，得到投影点 `F`。
3. 有向长度：沿 `b` 的方向从 `O` 读到 `F`，区分同向和反向。
4. 正负联系：归纳 `cos θ`、有向投影长度和数量积符号的同号关系。
