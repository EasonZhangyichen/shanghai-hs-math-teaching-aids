## 教学痛点

- 学生容易把投影长度看成普通线段长度，忽略它是有方向符号的量。
- 夹角为钝角时投影为负的原因不直观。
- 投影、垂线和数量积公式之间的联系容易被分散记忆。

## 初始设计意图

拖动两个向量改变夹角，联动显示垂足、有向投影长度、cos 值和正负变化。
