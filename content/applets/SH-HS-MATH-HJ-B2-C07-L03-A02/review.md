本资源能够严谨表达同一角 `x` 下 `sin x` 来自单位圆动点纵坐标，`cos x` 来自横坐标；关键角 `0`、`π/2`、`π`、`3π/2`、`2π` 的正弦值序列为 `0, 1, 0, -1, 0`，余弦值序列为 `1, 0, -1, 0, 1`。相位关系采用 `cos x = sin(x + π/2)`，并用 `x = 0` 检查方向：`cos 0 = 1 = sin(π/2)`，因此不是 `sin(x - π/2)`。
