# 正切函数图像生成器

资源 ID：`SH-HS-MATH-HJ-B2-C07-L06-A01`
版本：`0.1.0`
状态：`draft`
类型：HTML Applet 可运行原型

## 资源定位

本资源对应沪教版高中数学必修第二册第 7 章 7.4.1“正切函数的图像”。它把单位圆终边斜率、`tan x = sin x / cos x`、正切图像分支和渐近线放在同一个可拖动场景中，让学生看到正切曲线不是一条连续波形，而是在 `cos x = 0` 的位置断开并形成渐近线。

课堂主线是：

```text
单位圆终边斜率
-> tan x = sin x / cos x
-> 主值区间 (-π/2, π/2) 的分支
-> 靠近 x = π/2 + kπ 的左右趋势
-> 相邻分支对照
-> 归纳定义域、渐近线和周期 π
```

## 为什么需要数字化

静态板书可以描点画出正切曲线，但学生常常在三个地方出错：

- 忽略 `x = π/2 + kπ` 处无定义，把图像画成连续曲线。
- 只记住渐近线位置，不知道它来自 `cos x = 0`。
- 被正弦、余弦的周期 `2π` 干扰，把正切周期也写成 `2π`。

这个 Applet 只承担一个主要认知动作：逼近。学生拖动角度靠近渐近线时，应同时看到 `cos x` 变小、斜率线变陡、图像点迅速上升或下降，并据此解释为什么图像必须分段。

## 当前 HTML 原型能力

- 支持拖动单位圆终边或角度滑块，联动单位圆、斜率线和正切图像点。
- 支持显示 `cos x`、`tan x`、最近渐近线和到渐近线的距离。
- 支持切换观察焦点：主值区间、渐近线逼近、周期对照。
- 支持显示或隐藏单位圆、渐近线、周期对照和归纳面板。
- 支持播放、暂停、重置，并在接近渐近线时给出趋势提醒。
- 支持 Applet SDK 基础消息：`applet:ready`、`applet:stateChanged`、`applet:interaction`。

## 资源边界

本资源包含：

- Applet metadata、教师脚本、学生活动任务和草稿审核记录。
- `src/index.html` 可运行原型。
- 默认可视范围：`-3π/2 < x < 3π/2`，图像在 `x = π/2 + kπ` 处断开。
- 重点讨论 `y = tan x` 的定义域、渐近线和周期。

本资源暂不包含：

- 正切函数单调性的完整一般式证明。
- `y = A tan(ωx + φ)` 的参数变换。
- 用导数或极限语言严格证明趋向无穷。
- 自动生成诊断题与评分规则。
