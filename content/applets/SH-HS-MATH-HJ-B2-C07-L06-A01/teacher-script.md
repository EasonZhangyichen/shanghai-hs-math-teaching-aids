# 教师脚本：正切函数图像生成器

适用课时：必修第二册 7.4.1“正切函数的图像”
建议时长：20 分钟
资源状态：`draft`

## 教学目标

1. 让学生用单位圆终边斜率解释 `tan x` 的函数值来源。
2. 让学生把 `x = pi/2 + kpi` 的无定义位置与 `cos x = 0` 联系起来。
3. 让学生描述正切图像在渐近线左右两侧的逼近趋势。
4. 让学生通过 `x` 与 `x + pi` 的对照确认周期为 `pi`。

## 课前准备

- 初始观察角设为 `x = pi/4`。
- 默认显示单位圆、正切图像和渐近线。
- 黑板预留三块区域：定义域、渐近线、周期。

## 课堂流程

### 1. 从斜率进入正切值

时长：4 分钟

操作：

- 显示单位圆终边和主值区间内的正切图像。
- 拖动角度从 `0` 到 `pi/4`，让学生观察斜率线和图像点同步变化。

提问：

- 当前终边斜率如何从单位圆坐标得到？
- `tan x = sin x / cos x` 中，哪个量可能导致函数值不存在？

板书建议：

```text
tan x = sin x / cos x
当 cos x = 0 时，tan x 无定义
```

### 2. 观察主值区间分支

时长：4 分钟

操作：

- 切换到“主值区间”。
- 让学生记录 `-pi/4`、`0`、`pi/4` 三个点。

提问：

- 图像在 `(-pi/2, pi/2)` 内从左到右怎样变化？
- 为什么不能把端点 `-pi/2` 和 `pi/2` 画成实点？

### 3. 逼近渐近线

时长：6 分钟

操作：

- 切换到“逼近渐近线”。
- 从 `pi/2` 左侧缓慢靠近，再从右侧靠近。
- 读出 `cos x`、`tan x` 和到渐近线的距离。

提问链：

- 当 `x` 靠近 `pi/2` 时，`cos x` 的绝对值怎样变化？
- 左侧靠近时，`tan x` 往哪个方向变？
- 右侧靠近时，为什么方向相反？
- 这条竖线是图像的一部分吗？

板书建议：

```text
渐近线：x = pi/2 + kpi
左侧趋向 +∞，右侧趋向 -∞
```

### 4. 判断周期

时长：4 分钟

操作：

- 切换到“周期对照”，打开 `x + pi` 的紫色对照点。
- 拖动几个不同位置，比较两个点的纵坐标。

提问：

- `x` 与 `x + pi` 的终边方向有什么关系？
- 两个正切值为什么相等？
- 为什么正切周期不是 `2pi`？

板书建议：

```text
tan(x + pi) = tan x
最小正周期：pi
```

### 5. 收束与即时表达

时长：2 分钟

操作：

- 打开归纳面板。
- 让学生补全定义域、渐近线和周期。

学生完成一句话：

```text
正切图像要分段画，因为 ____________________；
它的渐近线是 ____________________；
周期是 ____________________。
```

## 常见误区与处理

| 误区 | 表现 | 处理方式 |
| --- | --- | --- |
| 忽略定义域断点 | 把正切曲线连成连续 S 形 | 关闭结论，只显示 `cos x` 读数，追问何时分母为 0。 |
| 渐近线来源不清 | 只背 `pi/2`，不能解释 | 回到 `tan x = sin x / cos x` 和单位圆横坐标。 |
| 趋向方向反了 | 左右两侧无穷方向混淆 | 在同一条渐近线两侧各取一个点，对比 `cos x` 的符号。 |
| 周期写成 2pi | 受正弦余弦迁移影响 | 打开 `x` 与 `x + pi` 对照，比较两个正切值。 |

## 本节不展开

- 正切函数性质的一般式完整证明。
- 参数正切函数 `y = A tan(omega x + phi)`。
- 用导数或严格极限语言证明渐近线。
