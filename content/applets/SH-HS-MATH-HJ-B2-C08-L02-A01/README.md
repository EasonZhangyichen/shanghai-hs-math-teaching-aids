# 向量加减法构造器

资源 ID：`SH-HS-MATH-HJ-B2-C08-L02-A01`

对应课时：`SH-HS-MATH-HJ-B2-C08-L02`「向量的加法和减法」

当前状态：`draft` / `self_checked_draft`

## 资源定位

本 Applet 用一组可拖拽的共起点向量 `a = OA`、`b = OB`，动态展示三种核心构造：

- 首尾相接：把 `b` 平移到 `a` 的终点，沿 `O → A → S` 的连续位移得到向量和 `a + b`。
- 平行四边形：`a`、`b` 共起点时，对角线表示同一个向量和 `a + b`。
- 减法与相反向量：向量差 `a - b = a + (-b)`，共起点时也可看作从 `B` 指向 `A` 的向量。

数字化必要性在于：学生能直接拖动向量，观察结果向量随方向和大小同步变化；教师可以在同一组向量上切换构造方式，避免把三角形法则、平行四边形法则和减法规则割裂成静态画法。

## 可操作内容

- 拖动 `A` 改变向量 `a`。
- 拖动 `B` 改变向量 `b`。
- 拖动 `O` 平移共同起点，保持两个向量本身不变。
- 切换「首尾相接」「平行四边形」「减法与相反向量」三种模式。
- 按「观察、构造、证据、归纳」四步揭示课堂信息。
- 开关辅助线和半格吸附，便于投屏观察几何位移。

## 数学边界

本资源聚焦向量加减法的几何构造，不扩展到 8.3 后续课时边界，也不做解析化运算题库训练。位移提示只作为当前拖拽状态的几何证据，用方向、大小、端点路径和网格中的水平/竖直移动来描述总位移，不引入坐标分量运算。
