# 教师脚本：向量加减法构造器

## 使用时机

建议用于「向量的加法和减法」新授或规则形成后的巩固环节，约 14 分钟。目标不是替代板书定义，而是让学生看见同一组向量在不同构造下的路径、方向、大小和横纵移动如何保持一致。

## 课堂流程

### 1. 观察向量 a、b，2 分钟

打开课件后停在「观察」。请学生读出蓝色向量 `a`、橙色向量 `b` 的方向和大致大小。拖动 `A` 或 `B`，追问：

- 哪个量变了，向量的起点还是终点？
- 只看线段长度，能不能判断向量相同？
- 拖动 `O` 后，两个向量本身有没有改变？

板书落点：向量由大小和方向决定，平移有向线段不改变向量。

### 2. 首尾相接得到 a + b，3 分钟

切到「首尾相接」并进入「构造」。让学生描述路径 `O -> A -> S`：

- 为什么要把 `b` 的起点接到 `a` 的终点？
- 结果向量为什么是从最初起点 `O` 指向最终终点 `S`？
- 如果把路径方向反过来，得到的还是 `a + b` 吗？

板书落点：`a + b` 是按路径顺序连续位移后的总位移。

### 3. 平行四边形对照，3 分钟

切到「平行四边形」。保持同一组 `a`、`b`，让学生比较首尾相接和对角线：

- 平行四边形的第四个顶点和首尾相接的终点是否重合？
- 对角线表示的位移从哪里出发，到哪里结束？
- 平行四边形法则为什么不是单纯补图形？

板书落点：共起点时，平行四边形对角线与首尾相接给出同一个 `a + b`。

### 4. 减法转化为相反向量，4 分钟

切到「减法与相反向量」。先停在「构造」，显示从 `A` 接上 `-b` 得到 `D`。追问：

- `-b` 的方向和 `b` 有什么关系？
- 为什么 `a - b` 可以写成 `a + (-b)`？
- 共起点时，从 `B` 到 `A` 的向量为什么也表示 `a - b`？
- 如果写成从 `A` 到 `B`，对应的是哪个向量？

板书落点：`a - b = a + (-b)`，并且共起点时 `BA` 表示 `a - b`，`AB` 表示 `b - a`。

### 5. 归纳与回收，2 分钟

进入「归纳」，让学生用一句话分别说明：

- 三角形法则看什么？
- 平行四边形法则看什么？
- 减法为什么要先找相反向量？

收束到学生任务中的记录表。提醒第 8 章课时边界仍需终核，本课只讨论 8.1.2 的几何构造和基础读数，不扩展到 8.3 后续运算。
