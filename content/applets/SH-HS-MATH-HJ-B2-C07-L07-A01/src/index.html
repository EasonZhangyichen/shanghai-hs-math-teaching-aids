课堂追问

只看高亮的一个连续定义区间：当 x 从左到右移动时，tan x 是否始终增大？

性质归纳

  • 定义域：x != pi/2 + kpi, k in Z
  • 值域：R
  • 周期：tan(x + pi) = tan x
  • 奇偶性：tan(-x) = -tan x
  • 单调性：在 (-pi/2 + kpi, pi/2 + kpi) 上递增
