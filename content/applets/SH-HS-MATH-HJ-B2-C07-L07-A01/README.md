# 正切性质分段观察

## 资源定位

本资源对应沪教版高中数学必修第二册第 7 章 7.4.2“正切函数的性质”。它承接 `SH-HS-MATH-HJ-B2-C07-L06-A01` 中对正切图像、定义域和渐近线的认识，进一步把单调性、值域、周期性和奇偶性放到同一张分段图像中比较。

## 教学痛点

- 学生容易说“正切函数在整个定义域上单调递增”，忽略定义域被渐近线切成不连续区间。
- 学生会觉得“值域是全体实数”和“有渐近线限制”相互矛盾。
- `π` 周期、奇函数和单调区间的一般表达容易混淆。

## 数字化切入点

```text
分段图像
-> 高亮单个定义区间
-> 同一区间内拖动比较单调性
-> x 与 x + π 比较周期
-> x 与 -x 比较奇对称
-> 回到性质的一般式
```

## 交互脚本概览

- 拖动 `x` 滑块，当前点在 `y = tan x` 上同步移动。
- 选择 `k = -1, 0, 1` 高亮对应定义区间 `(-π/2 + kπ, π/2 + kπ), k ∈ Z`。
- 打开周期对照，比较 `x` 和 `x + π` 的函数值。
- 打开奇对称对照，比较 `x` 和 `-x` 的点位关系。
- 切换“单调区间 / 周期 π / 奇函数 / 值域”四个焦点，逐步显示结论。

## 实现验收点

- `src/index.html` 可直接作为 iframe 入口运行。
- Applet 初始只高亮主值区间和当前点，结论需要教师逐步打开。
- 正切图像必须在 `x = π/2 + kπ, k ∈ Z` 处断开，并显示渐近线。
- 单调性表述必须限定在每个连续定义区间内。
- 周期、奇偶性和值域必须由可视点对或分支趋势支撑。
