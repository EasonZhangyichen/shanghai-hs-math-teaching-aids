# 教师脚本：正切性质分段观察

## 使用目标

用一张可交互的分段正切图像，帮助学生把“单调性、值域、周期性、奇偶性”从孤立结论转成可比较、可解释的图像性质。

## 课前准备

- 建议在学习“正切函数的图像”之后使用。
- 先确认学生能说出 `tan x = sin x / cos x`，并知道 `x = pi/2 + kpi` 处无定义。
- 打开 Applet 后保持默认模式：主值区间高亮、周期点和奇对称点暂不显示。

## 课堂流程

### 1. 限定讨论区间

操作：

- 保持焦点为“单调区间”。
- 选择 `k = 0`，只看 `(-pi/2, pi/2)`。
- 拖动 `x` 从左向右移动。

提问：

- 在这一个连续区间内，`x` 增大时 `tan x` 怎么变？
- 这个结论能不能直接跨过 `pi/2` 继续说？

板书建议：

```text
y = tan x 的定义域：x != pi/2 + kpi
单调递增区间：(-pi/2 + kpi, pi/2 + kpi), k in Z
不能说“在整个定义域上单调递增”
```

### 2. 比较相邻分支

操作：

- 切换到“周期 pi”。
- 打开周期对照点。
- 拖动 `x`，观察 `x` 与 `x + pi` 的高度。

提问：

- 两个点的横坐标相差多少？
- 它们的函数值有什么关系？
- 为什么正切函数周期是 `pi`，不是正弦、余弦的 `2pi`？

板书建议：

```text
tan(x + pi) = tan x
正切函数的周期：pi
```

### 3. 比较奇对称点

操作：

- 切换到“奇函数”。
- 打开奇对称点。
- 观察 `x` 与 `-x` 两点关于原点的位置。

提问：

- 两个点的横坐标、纵坐标分别有什么关系？
- 如何把图像上的对称关系写成函数式？

板书建议：

```text
tan(-x) = -tan x
y = tan x 是奇函数，图像关于原点对称
```

### 4. 解释值域

操作：

- 切换到“值域”。
- 仍然只看一个定义区间内的分支。
- 拖动观察点靠近区间两端，但不跨过渐近线。

提问：

- 分支向上、向下分别会逼近什么趋势？
- 为什么有渐近线，值域仍然可以是全体实数？

归纳：

```text
每个连续分支从负无穷延伸到正无穷
所以 y = tan x 的值域为 R
```

## 易错处理

| 错误表现 | 追问 | 回到 Applet 的操作 |
| --- | --- | --- |
| 说“整个定义域上递增” | 中间能跨过渐近线比较吗？ | 高亮相邻两个定义区间，指出中间断开。 |
| 把周期写成 `2pi` | `x` 和 `x + pi` 的点高是否相同？ | 打开周期对照点拖动。 |
| 奇偶性公式写反 | `x` 与 `-x` 的纵坐标是什么关系？ | 打开奇对称点。 |
| 认为有渐近线就不能取遍全体实数 | 在一个分支内能否到达任意给定高度？ | 切到值域焦点，拖动主值区间点。 |
