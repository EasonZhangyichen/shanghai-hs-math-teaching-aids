# 分镜：为什么正切图像有渐近线

## 核心叙事

```text
正切先看终边斜率
-> tan x = sin x / cos x
-> 终边接近 y 轴时 cos x 接近 0
-> 图像点逼近竖直渐近线
-> 渐近线处没有函数值，不能连线
-> 每隔 pi 重复一次
```

## 第 1 幕：正切先看斜率

左侧出现单位圆、终边和角 `x`，右侧出现正切函数坐标系。

教师可说：

> 正切图像不要先背形状。先回到定义：它可以看成终边的斜率，也可以写成 `sin x / cos x`。

数学焦点：

- 正切值来自同一个角的纵坐标与横坐标之比。
- 图像的横坐标仍是角 `x`，纵坐标是 `tan x`。

## 第 2 幕：cos x 越来越小

终边从 `0` 逐渐转到接近 `pi/2`。画面中水平的 `cos x` 段缩短，竖直的 `sin x` 段保持接近 1。

暂停问题：

> 当终边越来越接近 y 轴时，sin x 和 cos x 哪一个在接近 0？这会怎样影响 sin x / cos x？

期望回答：

- `cos x` 接近 0。
- `sin x` 接近 1。
- 分母越来越小，正切值快速增大。

## 第 3 幕：图像向渐近线逼近

右侧图像点沿 `y = tan x` 从原点附近上升，接近 `x = pi/2` 的竖直虚线。

教师追问：

- 图像点为什么越来越高？
- 它有没有真的到达 `x = pi/2`？

## 第 4 幕：这里没有函数值

画面高亮：

```text
cos x = 0
tan x is undefined
```

同时显示 `x = pi/2` 两侧的趋势：左侧趋向 `+infinity`，右侧趋向 `-infinity`。

暂停问题：

> 为什么图像不能穿过 `x = pi/2` 继续连起来？

期望回答：

- 在 `x = pi/2` 时 `cos x = 0`。
- `tan x = sin x / cos x` 没有定义。
- 渐近线是图像靠近但不能取到的位置，不是图像的一部分。

## 第 5 幕：隔 pi 重复一次

相邻周期淡入，箭头标注：

```text
tan(x + pi) = tan x
```

教师追问：

> 为什么正切图像的重复间隔是 `pi`，不是正弦余弦常见的 `2pi`？

期望回答：

- 终边转过 `pi` 后方向相反，但斜率相同。
- `sin` 和 `cos` 同时变号，比值不变。

## 第 6 幕：画图规则

画面右侧收束为三条规则：

```text
domain: x != pi/2 + k pi
asymptotes: x = pi/2 + k pi
period: pi
```

教师收束：

> 画正切图像时，先画不能跨过的竖直线，再在每个开区间内画向两侧逼近的分支。
