# 分镜：投影有向长度导入动画

## 核心叙事

```text
向量 b 给出正方向
→ 向量 a 的终点向 b 所在直线作垂线
→ 投影点 H 落在有向轴上
→ OH 不是普通线段长，而是有向投影长度
→ 投影长度 = |a|cosθ，符号由 H 相对 O 的位置决定
```

## 第 1 幕：先定方向

画面出现水平有向轴、向量 `b` 和同起点向量 `a`。`b` 的方向被标成“正方向”，反方向也有文字提示。夹角用 `θ` 标出。

教师可说：

> 先不要急着量长度。投影要先问：沿着谁的方向读数？

观看确认：

- 教师需先确认学生能看见 `b` 的方向就是读数正方向。
- 不在本幕展开数量积，只把“方向”作为后面读正负的铺垫。

## 第 2 幕：作垂线读投影点

从向量 `a` 的终点向 `b` 所在直线作垂线，交点记为 `H`。画面保留从 `O` 到 `H` 的有向线段。

建议暂停：约 `00:09-00:11`，等垂线、`H` 和有向线段 `OH` 都稳定后暂停。

暂停问题：

> 如果只看普通线段长，哪里会丢掉方向信息？

期望回答：

- 投影点在 `b` 的正方向时读正数。
- 投影点与 `O` 重合时读零。
- 投影点落在反方向时读负数。

教师口播衔接：

> 这里读的是有方向符号的长度，不是普通的非负线段长。

## 第 3 幕：锐角、直角、钝角比较

向量 `a` 连续转动，投影点 `H` 沿有向轴移动：

- 锐角：`H` 在正方向，`投影长度 = |a|cosθ > 0`。
- 直角：`H` 与 `O` 重合，`投影长度 = 0`。
- 钝角：`H` 在反方向，`投影长度 = |a|cosθ < 0`。

本幕只建立符号直觉，不展开完整数量积定义和运算律。

建议暂停：

- 约 `00:19-00:21`，直角读数稳定后可暂停，确认 `H` 与 `O` 重合时读数为 0。
- 约 `00:27-00:29`，钝角读数稳定后暂停，追问“为什么不是更长或更短的问题，而是符号变成负？”

教师口播衔接：

> 锐角、直角、钝角改变的不是“投影有没有长度”，而是投影点相对 `O` 的方向位置。

## 第 4 幕：预告下一课联系

画面最后保留有向投影线段和衔接口径：

```text
下一课：用有向投影理解数量积
```

教师追问：

> 为什么夹角变成钝角后，投影不是更长或更短的问题，而是符号变成负？

口播边界：

> 完整的数量积定义放到下一课处理。今天只把有向投影长度这件事看清楚。
