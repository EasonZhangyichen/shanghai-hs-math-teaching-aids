# 正切函数性质诊断

资源 ID：`SH-HS-MATH-HJ-B2-C07-L07-D01`

状态：`draft`
类型：Diagnosis 诊断资源

## 资源定位

本资源对应沪教版高中数学必修第二册第 7 章 7.4.2「正切函数的性质」。它放在 `SH-HS-MATH-HJ-B2-C07-L07-A01` 正切性质分段观察 Applet 之后，用 6 题快速诊断学生能否把正切函数性质放在“定义域断裂”的前提下表达。

核心诊断链路：

```text
先标定义域和渐近线
-> 选一个连续定义区间
-> 判断该段单调递增和值域覆盖
-> 用 pi 平移确认周期
-> 用 tan(-x) = -tan x 判断奇函数
-> 写出完整一般式
```

## 诊断焦点

- 是否遗漏 `x = pi/2 + kpi` 处无定义及对应竖直渐近线。
- 是否把“每个定义区间内递增”误说成“整个定义域上递增”。
- 是否能解释值域为 `R` 与竖直渐近线不矛盾。
- 是否把正切周期 `pi` 误写成正弦、余弦的 `2pi`。
- 是否能写出单调区间、渐近线和定义域的一般式。

## 课堂用法

- 新授课后：学生完成正切性质分段观察后，用本题组做 6 到 8 分钟即时诊断。
- 讲评前测：教师先看错因标签分布，再决定回到分段图像、渐近线来源动画或板书一般式。
- 分层订正：学生订正时必须补写一个定义区间、一个一般式或一句性质比较理由。
