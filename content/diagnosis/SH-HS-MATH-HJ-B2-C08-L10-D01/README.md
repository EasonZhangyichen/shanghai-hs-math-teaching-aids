# 向量应用第一步诊断

资源 ID：`SH-HS-MATH-HJ-B2-C08-L10-D01`

对应课时：`SH-HS-MATH-HJ-B2-C08-L10`「向量的应用」

本诊断包用于 8.4「向量的应用」课堂即时诊断。题组不批改完整证明过程，而是专门检查学生面对几何应用题时，能否根据题目特征选择第一步：先选基底与路径、先简洁建坐标设点、先使用数量积，还是先作投影或分解。

## 教学痛点

- 学生面对几何题时不知道先选基底、建坐标还是使用数量积。
- 几何语言转化为向量等式的第一步难，容易直接套公式。
- 证明过程中的向量路径、辅助点和坐标系选择缺少策略。
- 学生容易把坐标法当作万能入口，反而掩盖 8.4 向量法的工具选择价值。

## 错因标签

- `basis_path_gap`：平行四边形、中点、比例点或路径明显时，没有先选基底或拆路径。
- `coordinate_overreach`：默认复杂建坐标或列直线方程，忽略更直接的向量结构。
- `coordinate_setup_gap`：适合坐标法时，不能简洁选择原点、坐标轴和关键点。
- `dot_product_trigger_gap`：垂直、夹角、长度比较等信号出现时，没有想到数量积。
- `projection_decomposition_gap`：沿某方向分量、有效长度或垂直分解信号被遗漏。
- `point_ratio_expression_gap`：中点或比例点不能转化为同一出发点下的向量表达。
