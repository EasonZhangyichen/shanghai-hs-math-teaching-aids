# 教师说明

资源 ID：`SH-HS-MATH-HJ-B2-C08-L10-D01`

## 使用时机

建议在「向量的应用」第一课时后半段或第二课时开头使用。学生已经接触过向量线性运算、坐标表示、数量积和投影，但还没有形成“看到题目先判断工具”的策略时，本题组最有用。

## 8 到 10 分钟流程

1. 0 到 1 分钟：说明本诊断只看第一步选择，不要求完成整题证明。
2. 1 到 7 分钟：学生独立完成 6 题，Q05 和 Q06 可用条目式短答。
3. 7 到 8 分钟：教师查看最高频错因标签，选择一个入口回讲。
4. 8 到 10 分钟：学生任选一道错题订正，只改“第一步 + 理由”。

## 讲评方向

| 最高频错因 | 回讲入口 | 追问 |
| --- | --- | --- |
| `coordinate_overreach` | 并列展示“可坐标但不必坐标”的平行四边形或比例点题。 | “这道题的结构已经给了哪些向量关系？” |
| `basis_path_gap` | 画出首尾相接路径，选 AB、AD 或 AB、AC 为基向量。 | “目标向量能不能先走到一个已知点，再沿已知方向走？” |
| `point_ratio_expression_gap` | 板书比例点公式前，先让学生口头说“从 B 到 C 走了几分之几”。 | “D 是从 B 往 C 走，还是从 C 往 B 走？” |
| `dot_product_trigger_gap` | 把“垂直、夹角、锐钝、长度比较”写成数量积触发词。 | “目标是不是可以变成某个数量积为 0、为正或为负？” |
| `projection_decomposition_gap` | 回到投影有向长度，标出基准方向和垂直方向。 | “题目问的是合成，还是沿某方向的分量？” |
| `coordinate_setup_gap` | 用矩形或已给坐标题示范原点和坐标轴选择。 | “哪两条边天然垂直？哪个点设成原点最省事？” |

## 教师看板建议

- 若 `coordinate_overreach` 超过三分之一，先暂停完整证明讲评，统一做“题目特征 -> 第一工具”的分类。
- 若 `basis_path_gap` 与 `point_ratio_expression_gap` 同时高发，说明学生还没有把几何点位翻译成向量路径，应先回到 8.1 的加减法和数乘。
- 若 `dot_product_trigger_gap` 高发，补讲数量积不仅是计算公式，也是垂直和夹角的判定工具。
- 若 `projection_decomposition_gap` 高发，回看投影有向长度，不要急着进入坐标公式。
- 若 `coordinate_setup_gap` 高发，只选一题演示简洁坐标法，避免扩展到复杂解析几何。
