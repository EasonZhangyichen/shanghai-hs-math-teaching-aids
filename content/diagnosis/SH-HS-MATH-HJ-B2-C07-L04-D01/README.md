# 余弦性质误区诊断

资源 ID：`SH-HS-MATH-HJ-B2-C07-L04-D01`

对应课时：`SH-HS-MATH-HJ-B2-C07-L04`「余弦函数的性质」

本资源是 7.2.2 课后 6 到 8 分钟即时诊断，用于判断学生是否真正能通过比较正弦函数与余弦函数，掌握余弦函数的奇偶性、单调区间、关键点一般式和单位圆解释。它不作为普通练习题库，而是服务教师快速识别错因并决定回讲路径。

## 教学痛点

- 学生常把正弦函数的奇偶性和单调区间直接套到余弦函数。
- 最大值点、最小值点和零点的一般形式容易漏写周期。
- 同一性质在单位圆和图像中的解释不能互相转换。

## 认知动作

核心认知动作是「比较」：

- 比较正弦函数与余弦函数的奇偶性，检查是否把正弦的奇函数性质迁移到余弦。
- 比较余弦图像一个周期内的最大值点、最小值点和零点，检查关键点一般式是否完整。
- 比较递增半周期与递减半周期的端点，检查单调方向。
- 比较单位圆横坐标变化与图像走势，检查学生是否能在两种表征之间转换。

## 诊断目标

学生完成题组后，教师应能判断：

1. 学生能否确认 `y = cos x` 的定义域、值域、周期和偶函数性质。
2. 学生能否写出最大值点、最小值点、零点和单调区间的完整一般式。
3. 学生能否区分余弦图像的对称轴和对称中心。
4. 学生能否用单位圆横坐标解释余弦图像的性质。

## 错因标签

| 标签 | 含义 |
| --- | --- |
| `sine_transfer_error` | 把正弦函数的奇偶性、最大值点或单调区间直接套到余弦函数。 |
| `period_omission` | 只写一个周期内的区间或点，遗漏周期推广。 |
| `period_length_confusion` | 把相邻零点间隔误认为最小正周期。 |
| `monotonic_interval_reversal` | 递增、递减区间端点写反，或把含转折点区间当作单调区间。 |
| `axis_center_mixup` | 对称轴和对称中心对象混淆。 |
| `zero_extrema_formula_mixup` | 零点、最大值点、最小值点的一般式遗漏或互相误用。 |
| `unit_circle_graph_gap` | 不能用单位圆横坐标解释图像性质。 |

## 题组结构

- 6 题，建议 6 到 8 分钟完成。
- 题型包括单选、多选、简答和错误分析。
- 总分 10 分，掌握阈值为 75%。
- 每题都绑定错因标签，教师端优先展示标签统计，而不是只展示总分。
