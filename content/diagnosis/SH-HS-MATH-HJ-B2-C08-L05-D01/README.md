# 数量积正负误区诊断

资源 ID：`SH-HS-MATH-HJ-B2-C08-L05-D01`

对应课时：`SH-HS-MATH-HJ-B2-C08-L05`「向量的数量积的定义与运算律」

本诊断用于数量积定义与运算律新授后的 8 到 10 分钟即时分流。题组不把坐标公式作为主线，而是围绕 `a · b = |a||b|cosθ` 的几何意义、夹角分区、有向投影、零向量边界和结果类型设计。

## 教学痛点

- 会背定义式，但把锐角、直角、钝角对应的正、零、负判断混在一起。
- 把有向投影当作普通线段长度，不能解释钝角时数量积为负。
- 把 `a · b = 0` 直接等同于“两个向量垂直”，忽略零向量边界。
- 把数量积误认为结果仍是向量，或只用长度大小比较数量积。

## 认知动作

比较。

学生需要在六道题中反复比较：

- 锐角、直角、钝角下的数量积符号。
- 有向投影长度和普通线段长度。
- 零向量导致数量积为 0 与两个非零向量垂直导致数量积为 0。
- 数量积的“数量”结果和向量的方向信息。
- 长度乘积和夹角余弦共同决定数量积，而不是只看长度。
